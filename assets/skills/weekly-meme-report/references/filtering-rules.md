# 筛选规则（热梗周报 · 评论区实证 · 长窗版）

本文件是 SKILL.md 的详版补充，列出「收录什么 / 排除什么」的硬性规则。每条候选梗都要逐条过筛，不达标就降级或剔除。

---

## 核心哲学

> 真正牛逼的梗，不是热榜上挂着、媒体稿子里吹的梗，而是**评论区 / 弹幕里群众在自发玩的梗**。
>
> 串子玩梗的主战场就是评论区——评论区集体复读、对线、阴阳怪气的句式，才是能直接抄去用的武器。一个梗哪怕冲上热榜，只要评论区 / 弹幕里没人玩，它就不算牛逼，只是「被报道的梗」而已。
>
> 所以本 skill 把「评论区实证」作为收录的核心标准：必须通过真实样本证明群众在玩。时间窗上则采用「长窗」——不卡首发时间，只卡「现在还玩不玩」。一个几个月前首发、现在评论区仍在复读的串子梗，远比一个本周刚上热榜但评论区没人玩的"新梗"更有价值。"首发时间"降为参考信息，不再是一票否决。

---

## 一、数据源与优先级（四层流水线：精选池 → 验证 → 捕新 → 实证）

> 执行顺序见 SKILL.md Step 2。核心原则：**精选池给候选（效率），验证层证「现在还在玩」（硬数据），捕新层防漏（百科滞后），实证层给原句（B级/A级）**。四层都打，不跳层。
> **成本纪律（省 token，硬要求）**：默认走**轻量路径**——精选池抓取（gengtu 403 就跳过）→ 凭自带信息粗筛（不联网）→ 只对入围候选验证（档案已有实证直接取、gengtu 详情页优先、联网检索每候选最多 1 次）。**主 Agent 直搜，别拉子代理**（实测子代理分头跑烧 50 万+ token，只会照单执行不帮忙省）；搜索词优先站点限定；已知反爬坑（gengtu 403 / B站视频页 anti-bot / 抖音验证码 / hotdata JS 渲染）**抓不到就换源，不硬试**。深度模式（贴吧+虎扑+抖音定向+逐详情页）仅在用户明确要「尽量全」时打。

1. **精选池（主引擎，第一优先）**
   - gengtu 热梗索引（403 就跳过）+ 萌娘百科热词检索——这两个源已帮全网筛选，直接拿列表当候选主入口。
   - gengtu 详情页（`/memes/origin/<slug>/`）含结构化字段（起源 / 发展 / 识别点 / 常见衍生 / 传播方式）：① 起源自带外部来源链接（可溯源，直接当「来龙去脉」出处）；② 「识别点 / 常见衍生」常直接列出**评论区标签句式**（如「豪到我了」「就很你们懂吧」）；③ 站内梗图常带真实评论截图引用。
   - ⚠️ **精选 ≠ 现在还在玩**：百科收录只代表火过；候选仍要过「评论区实证」关（验证层 + 实证层）。
2. **主阵地（最高权重）**
   - 抖音 / B站 真实评论区、弹幕。
   - 检索时优先看：高赞评论、盖楼 / 嵌套回复链、弹幕集体复读。
3. **已过滤精选参考（候选池补充）**
   - B站「梗指南」「KPL梗指南」「游戏梗指南」类账号。
   - 这些账号已在做筛选，可作为候选池；但要求：**若能回主阵地评论区确认「群众真的在玩」最好（A 级）；用联网检索多源确认「正在被大量玩 / 二创 / 弹幕刷屏」也达标（B 级）**。仅有账号自己在盘点、无任何「群众在玩」证据的，不收。
4. **验证与捕新（硬数据）**
   - B站官方 API：热门榜（`api.bilibili.com/x/web-interface/ranking/v2`，带播放量 + 弹幕数）+ 热搜词（`api.bilibili.com/x/web-interface/search/square`）——弹幕数是「群众在玩」的硬指标；热搜词捕「刚冒头」。
   - 贴吧热议接口 `tieba.baidu.com/hottopic/browse/topicList`：30 条带讨论量。
   - 虎扑 `www.hupu.com/` 步行街热帖（带亮 / 回复）、AcFun `www.acfun.cn/` 热门（评论区 / 弹幕活跃）。
   - 抖音热榜（`hotdata.aipromptnav.com/douyin/`，JS 渲染抓不到条目时退回搜「抖音热搜榜 今天」）+ 抖音定向检索（年月用 `--month` 动态取，禁止写死）。
5. **辅助阵地（交叉验证）**
   - 虎扑步行街亮区、百度贴吧热门吧、NGA 论坛、游戏区热门内容。
   - 主要用来找电竞游戏圈、主播嘴硬 / 甩锅类串子梗。

> **小站证据纪律**：小站证据 = 阵地名 + 硬指标（浏览量 / 梗图数 / 讨论量 / 亮回复数），**绝不拿孤例当实证**；小站属 B 级证据的一部分，**不单独构成 A 级**；小站说「某梗在评论区玩」，仍要回大站找媒体引述 / 弹幕硬数据呼应。

## 二、评论区实证（核心收录门槛，全部满足才收）

对每条候选梗，必须找到真实评论区 / 弹幕样本，证明群众在自发玩这个句式。判断「群众在玩」的信号（**命中 2 个即达标；能抓到「盖楼」优先采信**）：

1. **弹幕复读**：某场景下满屏刷同一句式（如主播嘴硬时满屏「遥遥领先」「1252天心魔」）。
2. **高赞评论玩梗**：热评第一 / 高赞评论在玩梗或二创该句式。
3. **评论区复读机**：不同用户用同一句式回不同对象——说明句式已脱离原语境，成为通用对线武器。
4. **跨视频 / 跨博主**：不止一条视频 / 一个博主评论区出现，多个评论区都在玩同一句式（破圈强信号）。
5. **对线 / 阴阳应用**：评论区里能看到该句式被真正用于怼人、抬杠、阴阳怪气，而非单纯复述。
6. **【最精准】评论盖楼 / 嵌套回复链**：一条评论下，多人接力用同一句式盖楼对线，形成「楼主句 + N 层回复」的回复塔。**这是「群众真在玩」最硬的证据**——盖楼意味着不是一个人发完就走，而是大家在接话、在 riff、在对线，互相反复用这个梗。盖楼密度越高、层数越深，越说明这梗活在群众嘴里。
   - 抓法：在「用法实证」里直接贴「楼主句 + 2~3 层回复」的片段（见 output-format），比单条评论更精准地证明群众在玩，也最直观展示串子怎么接话、怎么阴阳。

### 未过门槛的处理
- **只有曝光没有群众玩**：热榜挂着、热搜吹、媒体稿，但评论区 / 弹幕没有自发包句式复读 / 对线的 → 标「仅曝光·评论区未玩」并**剔除**（那叫「被报道的梗」，不是牛逼的梗）。
- **搜不到评论区实证**：标「来源存疑」或舍去，绝不编造评论样本。

### B 级证据内部再分两档（可信度差一截，别混）
- **B1（一手源，可当实证直接引用）**：主流媒体 / 官方账号 / 梗百科（萌娘百科、gengtu 详情页）/ 官方平台硬数据（B站 API 播放·弹幕、贴吧热议接口）。
- **B2（二手源，只当候选线索，不能单独构成实证）**：SEO 聚合 / 转载站（特征：域名像教育机构 / 词典 / 聚合器，内容互相转载、无原创出处——如 lingoace、wukongsch、callcarbar、accio 这类；**增强识别：伪官方长域名 + URL 带 `?id=/article=/ssid=` 随机串 + 文末挂「校对」冒充权威，90% 是 B2**）+ 纯盘点视频标题。**B2 线索必须 ≥1 个 B1 源呼应才收**；只有 B2 支撑的梗标「证据弱（仅二手源）」或剔除。

### 抖音侧证据的诚实处理
- 抖音是 JS 渲染 + 验证码重灾区，原生证据经常拿不到。**拿不到就在报告里明说「抖音侧证据缺失，以 B站 / 媒体侧为主」，不要暗示有抖音实证**——宁缺毋假，别让速览目录看起来有抖音数据。

## 三、收录标准（全部满足才收）

1. **真·玩梗属性**：有可二次创作的固定句式 / 固定动作 / 固定语境，能被人「套用」。
2. **评论区 NOW 仍在玩（不限首发时间）**：本梗在抖音 / B站评论区、弹幕当前仍有群众在使用、复读、对线。首发时间早没关系，只要现在还活。
3. **串子向优先**：高强度对线梗、主播嘴硬 / 甩锅梗、弹幕集体刷屏阴阳句式；电竞游戏圈、搞笑互联网圈优先。
4. **热度够格**：≥2 阵地有传播证据，或单阵地爆发式（热榜高位 + 大量二创）。
5. **证据达标即可**：通过第二节 A 级（真实抓到评论区 / 弹幕 / 盖楼）或 B 级（联网检索多源确认「正在被大量玩 / 二创 / 弹幕刷屏」+ 可引用真实样本）任一即可，不强制实时进评论区。

> **关于「老梗」的处理（重点）**：
> - ✅ **仍可收**：首发时间早、但评论区 / 弹幕 NOW 仍在复读玩的梗（群众还在用，就是活梗）。在「来龙去脉」注明真实首发时间即可，不伪装成本周新梗。
> - ❌ **仍剔**：纯老梗翻新——只是换壳复读、没有任何新玩法 / 新变体、只是有人发帖「考古」一下，评论区没真的在玩的。

## 四、排除项（任何一条命中就剔）

- ❌ 温和无害、纯可爱、纯正能量的梗：如治愈系猫猫、可爱动物表情包、纯励志文案。
- ❌ 纯新闻 / 纯热搜事件：没有玩梗外壳的社会新闻、明星离婚、天气灾害等。
- ❌ 纯老梗翻新：见收录标准第 5 条。**注意：首发时间早、但评论区 NOW 仍在玩的活梗不在排除范围**（那是本 skill 要收的）。
- ❌ 微博系内容：微博热搜、微博搞笑博主推动的娱乐圈 / 饭圈内容。
- ❌ 小红书营销号推动的娱乐圈内容：明星造型、情感八卦等。
- ❌ **只有曝光没有群众玩**：热榜挂着、热搜吹、媒体稿，但评论区 / 弹幕没有自发包句式复读 / 对线的，一律剔除（见第二节）。
- ❌ 无法溯源且无佐证：来历不明、搜不到可靠出处的梗。

## 五、分级标准

- **破圈级大梗**：抖音 / B站 多阵地都在玩，评论区 / 弹幕密度高，已形成固定句式，主流媒体或梗百科已开始盘点。
- **发酵中潜力梗**：在单一主阵地内部热度高，正在向其他阵地渗透，评论区复读明显但尚未全平台破圈。
- **冷门趣味梗**：只在特定垂直圈子（如某个主播粉圈、某个游戏圈）内部玩，圈地自萌，外人可能 get 不到但内部复读密集。

## 六、来源可信度标注

- 对每个梗，尽量给出「来龙去脉」可靠出处 + 「评论区 / 弹幕用法实证」真实原句。
- **评论区原句即用法**：本 skill 不再另写、不编造「用法例句」。字段里放的真实原句（群众对线 / 阴阳 / 复读 / 嘴硬的原话）既当证据、又当用法示范，串子照抄即用。
- **优先抓盖楼**：能抓到「楼主句 + 多层回复」的回复链，就别只用单条评论——盖楼是群众真在玩的最精准证据，也最直观地展示用法（怎么接话、怎么阴阳）。
- 若只能凭检索摘要推断评论区在玩、拿不到原文 → 注明「评论区 / 弹幕用法实证：据检索摘要推断，存疑」，不要伪造评论、不要补编造的例句、不要编假盖楼。
- **禁止编造**：来历不明就不要补假故事；评论区样本也要真实，不编假评论、不编假例句、不编假盖楼。

---

## 七、输出与档案联动

- 每期报告按 output-format.md 三段式输出，但**同时必须把达标梗同步到 `热梗库/热梗档案.md`**。
- 档案是「长期武器库」，报告是「当期精选」。档案可以无限累积；报告每期精选 10–15 个（Deep 档可到 15–20），宁缺毋滥——检索先集齐 10 个以上有实证的，凑不满才少写并说明。
- 去重规则：归一化梗名（去空格 / 标点 / 大小写）比对，已存在的只更新「最近活跃」日期，不重复追加。
