# 输出格式（热梗周报 · 评论区实证 · 长窗版）

> **产出位置**：周报写入工作区根目录 `热梗库/` 下，文件名 `热梗周报_YYYY-MM-DD.md`（同日多期加后缀）。热梗库是本 skill 所有产出的唯一落脚点（档案 + 每期周报都在这），不写别处。

严格按以下三段式结构输出。每档内部**按热度从高到低排序**。关键原则：每个梗的「【评论区 / 弹幕用法实证】」字段既是最硬的证据，也是最直接的用法——串子照着原句就能抄去用，不另写、不编造「用法例句」。

### 字段填写纪律

- **精简风格（核心）**：正文每个梗只保留三样字段——**含义（一句话）、来龙去脉（精简 2–4 行）、【评论区 / 弹幕用法实证】（原句，命根子）**。不写标题党废话、不铺陈背景、不重复速览目录已说的话。宁可短而硬，不要长而水。
- **含义**：一句话（50 字内）点出「情绪 / 嘲讽对象 / 使用场景 / 为什么群众爱玩」，不要复述字面。
- **来龙去脉**：2–4 行讲清原始出处 + （若较早首发）真实首发时间 + 当前仍在玩的证据；搜不到标「来源存疑」，绝不可编造来历、不伪装新梗。
- **【评论区 / 弹幕用法实证】**：本 skill 的核心字段。放**真实**原句（媒体引述 / 弹幕硬数据 / 百科记载，B 级为默认路径，注出处与「非实时抓取」）——**原句即用法**，串子照抄即用，不另写、不编造「用法例句」。**盖楼（楼主句 + 多层回复）能抓到就贴（可遇不可求），抓不到不强求**——当前多数环境评论区反爬，A 级实抓拿不到是常态，B 级原句完全够用；若用户能提供截图 / 原句，可升级标注 A 级。拿不到原文就注明存疑，**绝不编假评论 / 假盖楼**。该字段一肩挑两职：既证明「群众真在玩」（证据），又展示「怎么玩」（用法）。
- **时间窗说明**：默认用本周窗口组织标题，但允许纳入窗口外、评论区仍在玩的活梗；本期出现的「老梗」要在来龙去脉里如实标注首发时间，不伪装成本周新梗。
- 总数控制在 **10–15 个（Deep 档可到 15–20）**，三档合计，宁缺毋滥；**只收评论区 / 弹幕有群众在玩的梗**。**检索先努力集齐 10 个以上有实证的梗再动笔**；实在凑不满 10 个才允许少写，且要在报告里说明差在哪。**绝不硬凑、绝不为凑数收「只有盘点标题、无实证」的梗**。
- 报告末尾附「剔除项（含原因）」：本轮考察过但没收录的梗，一行一个说明原因（温和 / 纯曝光 / 活性存疑 / 来源打架等），让读者知道边界在哪。
