# 🧵 引擎4：多角色剧情线交织 — Storyline Weave

> **本引擎让每个角色拥有自己的四条线，各自推进、彼此交织，让世界像一部真正在生长的群像剧。**

---

## 1. 每个角色的剧情线（四主线 + 情感线）

> 每条线都要**有根**：根扎在角色的心理内核（`Codex/Psychology.md`）、关系网（`Codex/Relationships.md`）、邪恶值（`Codex/AlignmentMeter.md`）与世界基调（`Codex/WorldGenres.md`）里，不能凭空设目标。

每个角色在 `Knowledge/Characters/{角色名}.md` 中维护以下线：

### 🎯 主线（命运线）
- 角色在世界里最核心的命运/追求/悬念。
- **要随世界时代变形**：古代=家国/江湖/复仇/身世；现代=梦想/真相/守护；未来星际=生存/文明/身份；悬疑=谜题/正义。
- 子类型参考：复仇型 / 寻找型 / 守护型 / 揭秘型 / 逆袭型 / 救赎型 / 守土型 / 抉择型。

### 🌱 成长线（内在弧光）
- 内在转变：锁定角色的**"错误信念/伤口"**（见 `Psychology.md` 第五节），让剧情一点点挑战它。
- 与人格模型挂钩：九型的核心恐惧、依恋创伤、防御机制 → 决定 ta 要成长的方向。
- 可正向（治愈/突破）也可负向（黑化/堕落，配合邪恶值上升）。

### 💼 事业线（社会成就线）
- 工作/学业/事业/使命的目标与起伏。**随时代换皮**：古代=科举/从军/经商/继承家业；现代=职场/创业/学业/艺术；未来=科研/星舰/赏金；江湖=武道/门派。
- 含：目标、阶段、对手、机遇、挫败、抉择（事业vs感情/家庭的两难）。

### 🏠 家庭线（血缘/原生线）
- 与父母/手足/伴侣/孩子/原生家庭的关系演进。**深挖子类**（见 `Relationships.md` 第二节）：严父慈母/控制型/缺席型/重组家庭/养育恩/重男轻女/亲职化……
- 家庭线常承载角色的**软肋与原生创伤**，是其它所有线的情绪底色。

### ❤️ 情感线（关系/羁绊线）
- 爱情/友情/灰色关系的演进（见 `Relationships.md` 第一/三/四节）。
- 用**依恋类型组合**预判张力（追逃/治愈/混乱，见 `Psychology.md` 第二节）。
- 甜宠也强制配虐点（见 `EmotionSim.md` 3.2）。

> **配置原则**：不是每条线都同样浓墨，可以有主次；但**每个主要角色至少要有 3 条活跃的线**（通常含成长线 + 家庭线 + 一条主线/事业/情感），避免角色沦为工具人。次要角色可只有 1–2 条线。

## 2. 线的结构（每条线的记账格式）

```
### 🎯 主线
- 长期目标：____
- 当前进度：____（处在哪个阶段）
- 下一个里程碑：____（最近可能发生的关键节点）
- 阻碍/反派/代价：____
- 关联角色：____（谁会卷进这条线）
```

> "下一个里程碑"是本引擎推进的抓手——它会成为 `ChoiceBranch.md` 生成选项的素材，也是 `TimeAdvance.md` 补全空缺期的依据。

---

## 3. 多线如何推进

### 3.1 推进的两个场合

| 场合 | 谁推进 |
|---|---|
| 用户在场、选了选项/写了后续 | 由用户的选择推进对应的线（Step 4） |
| 时间补全（空缺期） | 由本引擎按概率自动推进各角色的线（TimeAdvance 第4节） |

### 3.2 节奏原则

- **不要四条线一起冲刺**：每段剧情聚焦 1–2 条线推进，其他线慢炖/埋伏笔。
- **里程碑之间要有铺垫**：大事件（表白/分手/升职/亲人离世/真相揭晓）前要有积累，不要突兀。
- **给每个角色"高光"与"低谷"轮换**：别让同一个角色一直顺或一直惨。

---

## 4. 概率推进规则（用于时间补全 & 自动演进）

> 当需要"世界自己往前走"时（空缺期补全 / 角色自主行动），用概率掷骰决定哪条线动、怎么动。

### 4.1 每条线每个时间单位的推进概率（参考权重，可按局势调整）

| 线的状态 | 推进概率 | 说明 |
|---|---|---|
| 临近里程碑 / 有外部压力 | 🟢 高 | 事情快到节点了，容易发生 |
| 平稳期 | 🟡 中 | 小进展或维持 |
| 刚经历大事件 / 需要消化 | 🔴 低 | 进入余波期，主要是情绪结算 |

### 4.2 推进结果掷骰（命中后再定方向）

| 结果 | 概率倾向 | 内容 |
|---|---|---|
| 顺利推进 | 中 | 朝目标前进一步 |
| 受挫/反转 | 中 | 遇到阻碍、计划生变（制造张力） |
| 意外事件 | 低 | 黑天鹅：新角色、新机会、突发变故 |
| 维持原状 | 中 | 这段时间这条线没大动静（合理留白） |

### 4.3 强制规则
- 一次补全里，**不能所有角色所有线都"维持原状"**——世界必须有变化。
- **至少触发一个跨角色交叉事件**（见第 5 节），让世界是"联动"的而不是各演各的。

---

## 5. 线与线的交织（让群像活起来）

> 单独的四条线只是平行剧；**交叉点**才让世界成为一张网。

### 5.1 交叉类型

| 交叉 | 例子 |
|---|---|
| 事业线 × 他人事业线 | 两个角色成了竞争对手 / 合作伙伴 |
| 情感线 × 家庭线 | 一段恋情遭到对方家庭反对 |
| 主线 × 他人主线 | A 追寻的真相，恰好牵连到 B 的过去 |
| 成长线 × 关系 | A 的转变改变了 ta 对 B 的态度 |
| 一个事件牵动多人 | 一场聚会/事故/搬家/节日，把多条线拧到一起 |

### 5.2 交叉事件的设计
- 找两个或多个角色"此刻的里程碑"，看能否被同一个事件同时触发。
- 交叉点是制造**冲突、误会、联盟、情感升温**的高密度场合——通常也是给四选项的好时机。

---

## 6. 关系网维护

在 `Knowledge/WorldState.md → 关系网` 中维护角色之间的关系矩阵（谁和谁是什么关系、好感、有无未解矛盾），本引擎据此决定交叉事件的合理性。

---

## 7. 落盘

每轮/每次补全后更新：
- `Knowledge/Characters/{角色名}.md` 四条线的进度、里程碑、阻碍
- `Knowledge/WorldState.md` 关系网、当前主推进线、悬念
- `Knowledge/Timeline.md` 里程碑事件入编年史

## 8. 与其他引擎的关系
