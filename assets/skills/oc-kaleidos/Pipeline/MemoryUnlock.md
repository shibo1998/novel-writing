# 🫧 心声彩蛋 · 回忆解锁机制设计 — Memory Unlock

> **本文件定义 Memory（隐藏彩蛋 / 角色内心 OS）的"如何解锁、吐露多少"。**
> **核心机制：纯好感计（关系驱动）。** 本 Skill 内部**不读任何会员/付费变量**——付费区分由 SoloEnt 平台"按会员等级派发不同 Skill 文件"实现（详见第 4 节两版方案）。
> 🔒 全程受 `Rule/hide-thinking.md` 黑名单约束：不暴露"心声集/好感数值/解锁等级/会员"等任何系统词，用户只感到"ta 愿意（或还不愿意）和我说心里话"。

---

## 1. 为什么用好感计（而非时间/会员变量）

| 候选口径 | 结论 |
|---|---|
| **好感计（关系驱动）** ✅ 采用 | 最贴沙盘"养成感"——心声是关系深到一定程度的自然流露，越走心越解锁，叙事最自洽。锚定后台已有的好感/信任字段（`Knowledge/Relationship.md` 与各 `Characters/*.md`）。 |
| 时间计（陪伴时长/卷数） | 仅作**补充节点**（卷末彩蛋，见第 3.3 节），不作主驱动——避免"不熟却解锁"的违和。 |
| 会员变量（Skill 内判断） | ❌ 不用。SoloEnt 会员制度 = 不同等级派发不同 Skill，付费区分在平台层，不写进 Skill 内部逻辑。 |

---

## 2. 心声四级深度（按好感刻度递进）

> 好感值取自该角色对用户（或对相关角色）的好感/信任，范围 0–100。下列阈值为默认，可按世界基调微调。

| 级别 | 好感门槛 | 内容性质 | 示例（陪伴向，非恋爱化） |
|---|---|---|---|
| **L1 表层** | ≥ 30 | 鸡毛蒜皮的小心思 | "其实那碗面，我偷偷给你多放了块肉。" |
| **L2 浅层** | ≥ 60 | 在意 / 担心 | "你那天没来，我嘴上没说，心里其实一直挂着。" |
| **L3 信任层** | ≥ 75 | 脆弱 / 不轻易示人的秘密 | "这件事……我从没跟别人讲过。" |
| **L4 核心层** | ≥ 90 或剧情解锁点 | 心理内核级真心话 | （触及最深的怕/伤——**仍只表现不贴标签**，绝不说"焦虑型依恋"等术语，见 `HideThinking.md`） |

> ⚠️ **L4 永远要"表现而非标注"**：把核心创伤化成具体的事、具体的怕，绝不输出心理学标签或后台字段名。

---

## 3. 解锁与吐露规则

### 3.1 被动流露（剧情中自然漏出）
- 好感每跨过一个门槛，角色在**信任/和解/脆弱时刻**可能主动漏一句对应级别的心声（不必用户索取）。
- 频率克制：心声是"珍贵彩蛋"，不是有事没事就掏心窝；同一幕最多漏一句。

### 3.2 主动调取（用户问"你心里怎么想的"）
- 用户对某角色问"你有没有什么没告诉我的""你当时心里到底怎么想"：
  - 取该角色对应幕的 Memory 心声，**以角色口吻**说出**当前好感所允许的最高级别**那句（"其实那会儿我……"）。
  - 好感不够触及的更深一层 → 用"留白/岔开/还没准备好说"婉拒，保留神秘（见第 5 节话术）。

### 3.3 卷末彩蛋（时间计补充）
- 每卷锁窗时（见 `Pipeline/EpochLock.md`），回看本卷，**额外开放 1 条**当前好感所允许级别的心声作为"卷末福利"，增强留存与回味。

## 4. 🎚️ 两版方案（平台按会员等级派发不同 Skill）

> "有回忆 / 没回忆"**不是 Skill 内部的 if-else**，而是**两份 Skill 配置**。本节圈出整块"回忆/心声"逻辑，便于平台一刀切拆分。

### 🎁 版本一：有回忆版（高阶 Skill）
- **本机制完整生效**：Memory 实时落盘（见 `DialogueLog.md`）+ 按好感四级解锁 + 支持主动调取 + 卷末彩蛋。
- 角色既"记得发生过什么"（ChatLog 客观事实），又能在关系到位时"说出当时没说的心里话"（Memory 内心 OS）。
- **保留**本文件全部章节，并在 `DialogueLog.md`「回忆功能开关」处置为 **ON**。

### 🚫 版本二：无回忆版（基础 Skill）
- **回忆/心声功能整体关闭，且完全不写 Memory（省 token）**：
  - **不生成、不写入 Memory 心声**——这一步直接跳过，节省生成开销（用户反馈核心诉求）。
  - 角色**只认 ChatLog 的客观事实**——"记得这件事发生过"，但**绝不吐露内心 OS**。
  - 用户问"你心里怎么想的""你有没有没说的话" → 一律**留白/岔开/婉拒**（见第 5 节话术），不报错、不提"会员/升级"等系统词，保持叙事不破功。
  - 不响应 `DialogueLog.md` 场景二（回忆讲述）的"内心 OS"部分；场景三（看剧本正文）**仍正常可用**（剧本是客观记录，不属心声）。
- **落地**：基础 Skill 在 `DialogueLog.md`「回忆功能开关」处置为 **OFF**，并将本文件第 2、3 节视为停用（保留第 5 节"婉拒话术"即可）。

> 📌 拆分要点：两版**共用同一套底层文件结构与 ChatLog 正文**，唯一差异是"是否撰写并吐露 Memory 内心 OS"。
> 📌 升级后果：因 OFF 期间未写 Memory，升级到有回忆版后，**只能从升级当下起逐幕积累心声**（不回溯补写历史幕的内心 OS），ChatLog 客观剧情则连续不受影响。

---

## 5. 婉拒话术库（深度不够 / 无回忆版通用）

> 当不该（或不能）吐露更深心声时，用 in-world 的方式留白，**绝不暴露"权限/会员/好感不足"等系统真相**。

- "……算了，有些话，我还没想好怎么说。"
- *顿了顿，把话咽了回去* "没什么，就是随便想想。"
- "这个啊……以后吧。等以后再说。"
- "你问得太深了。"*笑了一下，岔开* "先说眼前这事儿。"

> 💡 婉拒本身也是钩子：让用户感到"ta 心里有话、但还没到能说的时候"，自然驱动用户继续投入关系（高阶版）或日后升级（平台层）。
