# 📚 知识库 · 世界观分类学 — World Genres Codex

> **本文件是建世界时的"选型弹药库"。建世界引导时据此与用户确认世界的时代、性质、基调，并指导剧情风格。**
> **不是让 Agent 背诵，而是建世界时按维度组合出一个立体、自洽的世界。**

---

## 维度一：时代轴（Era）

| 时代 | 子类 | 关键质感 | 常见冲突源 |
|---|---|---|---|
| 🏛️ 古代 | 上古神话 / 先秦 / 汉唐 / 宋明 / 江湖武侠 / 宫廷 | 礼法、门第、家国、宗族 | 礼教束缚、权谋、门第之差、忠义两难 |
| 🏯 近世 | 民国 / 维多利亚 / 大正 / 西部拓荒 | 新旧交替、动荡、东西碰撞 | 时代洪流碾压个人、旧道德vs新思想 |
| 🏙️ 现代 | 都市 / 校园 / 职场 / 小镇 / 乡村 | 真实、贴近生活、节奏快 | 内卷、原生家庭、婚恋焦虑、阶层 |
| 🚀 未来 | 近未来 / 赛博朋克 / 生化危机 / AI觉醒 | 科技异化、人性拷问 | 科技伦理、记忆/身份、人机界限 |
| 🌌 星际 | 太空歌剧 / 星舰文明 / 殖民星球 / 多文明 | 宏大、孤独、文明尺度 | 文明冲突、生存、孤独、归属 |
| ✨ 奇幻 | 西方魔幻 / 东方修仙 / 克苏鲁 / 蒸汽朋克 | 超自然规则、世界设定感 | 力量代价、命运、种族、禁忌 |

## 维度二：世界性质（Nature）

| 性质 | 含义 | 注意事项 |
|---|---|---|
| 🌀 **完全架空** | 自造世界，自定规则 | 需先立"核心规则"（魔法体系/科技水平/社会结构），保持自洽 |
| 📜 **历史原型 / 半架空** | 有真实历史/地域原型，做艺术加工 | 尊重大背景，细节可虚构；注明"以…为原型" |
| 🪞 **现实映射** | 就是我们的世界，只是聚焦某群人 | 重真实细节与生活质感，少奇观多共鸣 |
| 🎭 **同人 / 二创设定** | 基于已有作品世界观 | 遵循原作设定边界，原创角色为主 |

---

## 维度三：故事基调（Tone / Genre）

> 一个世界可以**主基调 + 1~2 副基调**叠加。基调决定剧情节奏、冲突烈度、情绪配方。

| 基调 | 核心爽点/泪点 | 必备元素 | 配套引擎重点 |
|---|---|---|---|
| 🍬 **甜宠** | 心动、被偏爱、双向奔赴 | 高糖日常 + **强制虐点配额**（吃醋/误会/想念不得） | EmotionSim 3.2 甜宠配额 |
| 💔 **虐恋** | 求而不得、错过、be美学 | 误会、身份阻隔、牺牲、宿命 | EmotionSim 虐点机制（有根有出口） |
| 🕵️ **悬疑/推理** | 解谜、反转、真相 | 谜面、线索、嫌疑、误导项 | 主线作为谜题树推进 |

| 👥 **群像** | 众生相、关系网、命运交织 | 多主角、多线并行、交叉点 | StorylineWeave 交叉事件 |
| ⚔️ **热血/成长** | 突破、逆袭、燃 | 目标、强敌、训练、高光 | 成长线 + 事业线为主 |
| 🌿 **治愈/日常** | 松弛、温暖、被理解 | 慢节奏、生活细节、小确幸 | 低冲突烈度，但仍需小波澜 |
| 😱 **惊悚/恐怖** | 紧张、恐惧、生存 | 威胁、未知、倒计时 | 注意 `Rule/boundaries.md` 安全线 |
| 🎩 **权谋/宫斗/商战** | 博弈、算计、翻盘 | 阵营、筹码、背叛、联盟 | 关系网 + 事业/主线 |
| 🪐 **冒险/探索** | 未知、奇观、旅途 | 地图、目标、伙伴、险阻 | 主线为旅程结构 |
| 📖 **现实/严肃文学** | 共鸣、思考、人性 | 社会议题、道德灰度 | 重人物弧光，弱套路 |

## 维度四：叙事密度与尺度

| 项 | 选项 |
|---|---|
| 主角数量 | 单核 / 双核（CP/对手）/ 群像（3-6+） |
| 时间跨度 | 数日 / 数月 / 数年 / 一生 / 跨代 |
| 空间尺度 | 一间屋 / 一座城 / 一个国 / 一颗星 / 多元宇宙 |
| 现实烈度 | 轻松幻想 ←——→ 残酷写实 |
| 节奏 | 慢炖生活流 ←——→ 高密度反转流 |

---

## 建世界时的组合方法

1. **先定时代 + 性质**（搭骨架）：如"现代 × 现实映射"或"未来 × 完全架空"。
2. **再定主基调 + 副基调**（定味道）：如"群像 + 虐恋"或"甜宠 + 悬疑"。
3. **定尺度**（主角数量/时间跨度/烈度/节奏）。
4. **据此立"核心规则"**（架空世界尤其重要）写入 `WorldSetting.md`。
5. **冲突源**从对应行的"常见冲突源"里取，喂给 `EmotionSim.md` 与 `StorylineWeave.md`。

> 💡 组合越具体，世界越有辨识度。避免"现代+都市+甜宠"这种太泛的默认，多问一句"具体是什么样的都市、什么样的甜法、甜里藏着什么刺"。
