# 💞 知识库 · 关系与情感分类学 — Relationships Codex

> **本文件是"人与人之间各种关系"的弹药库，供建角色、织关系网、设计冲突与情感线时取用。**
> **目的：让角色之间的羁绊不只是"朋友/恋人"两档，而是有层次、有张力、有具体质感的真实关系。**

---

## 一、爱情线（Romance）子类型

| 类型 | 质感 | 天然张力/虐点 |
|---|---|---|
| 双向奔赴 | 互相心动、势均力敌 | 谁先捅破、外部阻力 |
| 单恋/暗恋 | 求而不得、小心翼翼 | 被忽视、表错情、错过时机 |
| 先婚后爱 | 契约开局、日久生情 | 信任建立、第三者、契约到期 |
| 青梅竹马 | 熟悉、默契、错位 | 习惯≠爱情、新人介入、长大后的疏离 |
| 欢喜冤家 | 互怼、不打不相识 | 嘴硬心软、面子之争 |
| 破镜重圆 | 曾相爱又分开 | 旧伤、心结、信任难重建 |
| 师生/上下级/禁忌恋 | 身份不对等 | 世俗眼光、权力差、道德困境 |
| 异地/异世界/跨次元 | 距离阻隔 | 见不到、时差、归属难 |
| 救赎式 | 一方拉另一方出深渊 | 拯救者疲惫、依赖vs独立 |
| be美学/宿命悲恋 | 注定错过/失去 | 牺牲、误会到死、时代碾压 |

> 💡 **甜宠也要有刺**：再甜的恋爱也要配 `EmotionSim.md` 的虐点（吃醋、患得患失、为对方好却被误解、想念而不得）。

## 二、亲情线（Family）子类型

| 维度 | 子类 | 常见张力 |
|---|---|---|
| 父母-子女 | 严父/慈父、控制型母亲、缺席型父母、丧偶式育儿 | 期待绑架、代沟、偏心、未说出口的爱 |
| 手足 | 长子长女责任、被偏爱的幼子、双胞胎、重组家庭兄妹 | 资源争夺、比较、护短、长兄如父 |
| 隔代 | 祖孙、被祖辈带大 | 观念差、衰老与告别、隔代溺爱 |
| 婚姻内 | 夫妻、姻亲（婆媳/翁婿） | 育儿分歧、原生家庭介入、中年危机 |
| 非血缘亲情 | 养父母、继亲、收养、相依为命 | 身份认同、"算不算一家人"、血缘执念 |
| 原生家庭创伤 | 重男轻女、家暴阴影、被抛弃、长期忽视 | 一生的底色，常是软肋来源 |

> 📌 家庭线常是角色**软肋与行为模式的根源**，应与 `Psychology.md` 的"依恋类型/原生家庭"联动。

## 三、友情/同伴线（Friendship & Bonds）子类型

| 类型 | 质感 | 张力 |
|---|---|---|
| 生死之交 | 共过患难、绝对信任 | 一旦背叛最痛 |
| 损友/互怼挚友 | 嘴贱但够意思 | 玩笑越界、关键时刻才见真心 |
| 良师益友 | 引路、点拨 | 超越、青出于蓝、理念分歧 |
| 战友/同袍 | 并肩作战 | 牺牲、立场分裂 |
| 竞争对手→惺惺相惜 | 棋逢对手 | 既想赢又懂对方 |
| 塑料姐妹/塑料兄弟 | 表面好、暗较劲 | 比较、嫉妒、塑料破裂 |
| 萍水相逢的善意 | 短暂却深刻 | 来不及深交就分别 |

## 四、张力型/灰色关系（Adversarial & Gray）

| 类型 | 说明 |
|---|---|
| 宿敌/世仇 | 立场对立、不死不休，但可能互相理解 |
| 亦敌亦友 | 时而合作时而对抗 |
| 利用与被利用 | 各取所需的同盟，随时可能反目 |
| 背叛者/卧底 | 身份双重，情感与立场撕裂 |
| 救赎者与被救赎者 | 道德落差中的牵引 |
| 操控与被操控（PUA/煤气灯） | ⚠️ 可作为虐点/反派关系，但需 `Rule/boundaries.md` 把关，不美化 |

## 五、关系的"动态演化"（关系不是固定的）

关系会随剧情**升级或降级**，记录在 `WorldState.md → 关系网`：

```
陌生 → 相识 → 熟悉 → 信任/亲近 → 亲密/羁绊深厚
                          ↓（冲突/背叛/误会）
              裂痕 → 疏远/冷战 → 决裂 → （和解契机）→ 修复（带疤）
```

- 升级要有**积累与契机**，不能一步登天。
- 降级（裂痕/决裂）正是虐点与戏剧的来源，由 `EmotionSim.md` 的矛盾积累驱动。
- 修复后**不回原点**，带着这段经历的痕迹。

---

## 六、给 Agent 的取用建议

- 建角色时，为 ta 至少配置 **2-3 段不同类型的关系**（如：一段爱情线 + 一段原生家庭张力 + 一个损友）。
- 设计冲突时，先看这段关系**天然的张力点**在哪，从那里下刀最真实。
- 多用灰色关系制造层次，避免"非好即坏"的扁平人物网。
- 关系类型要与角色的**依恋类型、人格、原生家庭**（见 `Psychology.md`）逻辑自洽。
