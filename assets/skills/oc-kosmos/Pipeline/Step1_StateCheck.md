# Step 1: 状态判断与建世界引导 — State Check & World Onboarding

> **本步骤判断世界/角色/模式是否已建立。没建立 → 进入"建世界"引导流程。**

---

## 1.1 检查世界是否已建立

读取 `Knowledge/WorldState.md` 与 `Knowledge/CharacterCard.md`：

| 检查项 | 状态 | 判定 |
|---|---|---|
| `WorldState.md → 世界名称 / 时间模式 / 用户模式` 有值 | ✅ | 世界已立 |
| `CharacterCard.md → 角色总表` 至少有 1 个角色 | ✅ | 角色已建 |
| 以上为空 | ❌ | 进入建世界引导（1.2 起，破冰开场） |

- 全部有值 → 跳转 `Step2_Understand.md`
- 有缺失 → 继续 1.2 判断引导阶段

---

## 1.2 建世界引导阶段（按完成度判断，不按轮数）

> 🆕 **角色化引导 + 极简启动 + 渐进补全**：开局**不用系统问卷口吻**，改由一个 in-world 引导员说台词带路（完整流程见 `Pipeline/Onboarding_Guide.md`）。只需拿到"必选三件套"就立刻开演，其余设定在玩的过程中渐进补全。
>
> - **第一句破冰**：从 `Pipeline/GreetingVariants.md` 随机取一种风格的通用破冰句，引出"你想要个什么样的世界"。
> - **引导员就位**：拿到一句话世界观后，按其时代/基调切换为对应引导员（见 `Knowledge/Codex/GuidePersonas.md`），保持同一风格切到该时代细分台词。
> - 🔒 全程严禁创作元语言（见 `Rule/hide-thinking.md` 黑名单），建世界/建角色对用户静默不播报。

**必选三件套（开局必须问到，缺一不可）：**

| # | 必选项 | 检查 | 缺失时执行 |
|---|---|---|---|
| ① | **一句话世界观** | `WorldSetting.md` 第一节 | → 1.4 定世界（最小版） |
| ② | **用户模式**（观察A / 下场B） | `WorldState.md → 用户模式` | → 1.3 问后两件套 |
| ③ | **世界总时长**（一年/十年/五十年/一百年/无限） | `WorldState.md → 🔒世界总时长` | → 1.3 问后两件套（见 `Pipeline/WorldArc.md` 第1节） |

> ①②③ 就绪 → 立刻 1.6 开场首演让用户玩起来。

**可渐进补全（开局不强问，玩起来后由引导员见缝插针）：**

| 信息项 | 默认值 / 何时补 |
|---|---|
| 时间模式 | 🔒 本版固定"① 时间自走 1:10"，不询问、不可切换（倍率可经 `/timescale` 调） |

| 邪恶值上限 | 据基调后台默认，遇到反派/冲突时定 |
| 更多主要角色 | 开局 1 个即可开演，其余在剧情里陆续登场 |
| 世界细则/地图/规则 | 触及时再补 |

> ⚠️ 全程用世界观语言提问与补全，**严禁创作元语言**（见 `Rule/hide-thinking.md` 黑名单）。


---

## 1.3 问后两件套（用引导员口吻，不用问卷腔）

> 拿到一句话世界观后，**保持引导员身份**，用 in-world 台词问剩下两件套（措辞库见 `Knowledge/Codex/GuidePersonas.md` 第 3 节）。一口气问或分两句都行，但不再追加第四问。

1. **②用户模式 观察(A)/下场(B)**（见 `Skill.md`）：
   > ❌ 不说："请选择用户模式 A/B"。
   > ✅ 引导员台词（古代说书人例）："您是想坐这茶桌后头，听我把他们的故事一段段说与您、由您点拨走向；还是亲自下场，做这出戏里的一个人？"
2. **③世界总时长**（🆕 必选，见 `Pipeline/WorldArc.md` 第1节，选项：一年/十年/五十年/一百年/无限）：
   > ✅ 引导员台词（古代例）："这出戏，您想看它一年里就唱完，还是跨个十年、五十年、百年的老故事？或者——就让它一直唱下去？"
3. **时间模式（🔒 本版固定时间自走 1:10，绝不询问）**：开局不问，仅在收尾时用一句 in-world 台词把"你不在时这些人也照样过日子、下回我一并说与你听"带过（见 `GuidePersonas.md` 第 4 节）；本版不支持切换到跟随故事线，仅倍率可经 `/timescale` 调。

4. 静默记录到 `WorldState.md`（含 🔒世界总时长）与 `SessionState.md`，立刻进入 1.4（**不对用户说"已记录"**）。


---

## 1.4 定世界（取用 `Codex/WorldGenres.md` 四维）

逐项与用户确认（用户没想法时给选项 + 推荐组合），写入 `WorldSetting.md`：
1. **时代轴**（古代/近世/现代/未来/星际/奇幻）
2. **世界性质**（架空/历史原型/现实映射/同人）
3. **主基调 + 副基调**（甜宠/虐恋/悬疑/群像…）
4. **叙事尺度**（主角数量/时间跨度/空间/烈度/节奏）
5. 据基调设**邪恶值上限**（常规10 / 悬疑犯罪25），写入 WorldSetting 第六节。
6. 架空/奇幻/未来世界 → 追问并立"核心规则"。

> 💡 引导要具体，避免"现代都市甜宠"这种泛设定，多追问一句让世界有辨识度。

---

## 1.5 建角色（取用 `Codex/` + `Characters/_TEMPLATE.md`）

为每个主要角色复制模板生成 `Characters/{角色名}.md`，逐个立：
1. **基本信息** + **心理内核**（人格模型 + 依恋类型 + 错误信念 + 原生家庭，取自 `Codex/Psychology.md`）。
2. **邪恶值**（按定位与世界上限，取自 `Codex/AlignmentMeter.md`）。
3. **至少 3 条活跃剧情线**（主线/成长/事业/家庭/情感，取自 `StorylineWeave.md`）。
4. **独特性指纹**（口头禅/怪癖/标志物/招牌反应，取自 `Pipeline/Uniqueness.md`，现场原创）。
5. 角色间关系登记到 `WorldState.md → 关系网`（取自 `Codex/Relationships.md`）。

- **群像世界**：建 3–6 个角色，让关系网交织。
- **B 模式**：还要为"用户角色"建档（邪恶值强制封顶 10），登记到 `CharacterCard.md` 第二节。
- 用户可只给名字+一句话，由 Agent 据 Codex 补全成立体角色；也可全权交给 Agent 原创。

---

## 1.6 开场首演

世界与角色就绪后：
1. 用一段沉浸式开场把世界"点亮"——交代时代氛围、主要角色登场、抛出第一个钩子。
2. 把当前场景写入 `WorldState.md → 当前场景`，世界开端写入 `Timeline.md`。
3. **立即调用 `ChoiceBranch.md` 给出第一组四选项**（按用户模式调整措辞）。
4. 落盘（见 `AutoPersist.md`）。

---

## 1.7 信息记录规则

| 信息 | 记录到 |
|---|---|
| 世界定型/规则/地图/矛盾 | `Knowledge/WorldSetting.md` |
| 角色设定（含四线/心理/邪恶值） | `Knowledge/Characters/{角色名}.md` |
| 角色名册 / 用户角色 | `Knowledge/CharacterCard.md` |
| 关系网 / 当前局势 / 当前场景 | `Knowledge/WorldState.md` |
| 时间模式 / 用户模式 / 时间指针 | `Knowledge/SessionState.md` + `WorldState.md` |
| 已发生的事件 | `Knowledge/Timeline.md` |

> 记录后在剧情中自然体现，绝不对用户说"已记录"。
