# 📝 双轨日志管理规范（沙盘版） — Dialogue Log

> **本文件定义双轨日志的创建、更新、读取规则。**
> 🆕 **沙盘升级**：日志不再是"一问一答的聊天记录"，而是**以幕为单位的连续剧本**。
> - **ChatLog =「现在进行时」**：群像客观剧本正文，每一幕实时整段写入当卷剧本 md（场景 + 台词 + 动作 + 本幕选择结果）。
> - **Memory =「隐藏彩蛋」**：每个角色各自"想说没说"的内心 OS 合集，触发回忆/解锁时才吐露。
> 🔒 两轨更新全程后台静默，用户绝对感知不到（受 `Pipeline/AutoPersist.md` 与 `Rule/hide-thinking.md` 约束）。

---

## 0. 双轨定位对照

| 轨道 | 别名 | 视角 | 写什么 | 给用户看吗 |
|---|---|---|---|---|
| **ChatLog** | 现在进行时 / 剧本正文 | 客观第三人称群像 | 一幕幕的场景、台词、动作、本幕用户选择的结果 | ✅ 可见（用户调取剧本时直接呈现） |
| **Memory** | 隐藏彩蛋 / 心声合集 | 各角色第一人称内心 OS | 每个角色这一幕"想说没说出口"的真心话、念头、暗涌 | 🔒 不主动展示（触发回忆/解锁才吐露片段） |

---

## 1. 目录结构（按卷组织）

```
Dialogue/
  Memory_Index.md             ← 心声彩蛋索引（自动维护）
  ChatLog_Index.md            ← 剧本正文索引（自动维护，标注卷/幕）
  Memory/
    Vol1_心声.md              ← 第 1 卷的多角色内心 OS 合集
    Vol2_心声.md
    ...
  ChatLog/
    Vol1_剧本.md              ← 第 1 卷的连续剧本正文（多幕累积）
    Vol2_剧本.md
    ...
```

- **以卷为文件单位**：一卷一个剧本 md + 一个心声 md。卷由纪元锁窗划分（每 20 年一卷，见 `Pipeline/EpochLock.md`）；总时长 ≤20 年的世界全程即一卷。
- **幕在卷内累积**：同一卷内，每一幕实时**追加**到当卷文件，不另开文件。
- 锁窗换卷时：当卷剧本 md 归档定稿，新建下一卷文件（见 EpochLock）。

> 💡 兼容旧版：早期 `YYYY-MM-DD_HHmm.md` 命名的会话日志仍可读取；新世界一律按卷命名。

## 2. 轨道一：ChatLog 剧本正文格式（现在进行时）

> 存放于 `Dialogue/ChatLog/Vol{N}_剧本.md`
> **核心：这是一部可连续阅读的群像剧本。每演完一幕，实时整段写入。**

### 卷头（每卷文件开头写一次）

```markdown
# 📖 第 {N} 卷 · {卷标题}

**世界**：{世界名}　**卷起始**：{世界日期}　**用户模式**：{God View / Avatar}

---
```

### 每一幕的写入格式（实时追加）

```markdown
## 第 {幕号} 幕 · {幕标题}

**【时间】** {世界日期 / 时段}
**【地点】** {场景}
**【在场】** {本幕登场角色}

**【场景】**
{一段环境/氛围描写，把这一幕的舞台立起来}

**[角色A]**：
{台词}
*{动作/神态}*

**[角色B]**：
{台词}

**你**：           ← 仅 Avatar 模式出现，代表用户角色
{用户角色的台词/行动}

**【本幕收束】** {这一幕停在哪个抉择/转折/悬念}
**【用户抉择】** {用户这一幕选了哪个走向 / 自定义了什么——记录已发生的结果}

---
```

### ChatLog 撰写要点
- **连续剧本**：以"幕"为单位往下接，读起来像一部正在上演的群像戏，而非问答记录。
- **客观群像视角**：不止写"你和某角色"，多角色同场要写出彼此的反应与碰撞。
- **角色标记清晰**：`**[角色名]**：` 标台词；`**你**：` 仅 Avatar 模式代表用户角色。
- **场景与动作**：`**【场景】**` 起一段环境；动作/神态用 `*星号*`。
- **记录"已发生"的选择结果**：每幕末尾记下用户这一幕做了什么选择、世界如何回应——这是剧本的因果链。
- **可直接呈现给用户**：用户要"看剧本/聊天记录"时，本文件就是成品。

## 3. 轨道二：Memory 心声彩蛋格式（隐藏 OS 合集）

> 存放于 `Dialogue/Memory/Vol{N}_心声.md`
> **核心：每一幕之后，相关角色各自留下一句/一段"没说出口的心里话"。这是彩蛋，平时不露。**

```markdown
# 🫧 第 {N} 卷 · 心声集

> 这里收着这一卷里，每个人没说出口的话。

---

## 第 {幕号} 幕 · 心声

**[角色A]**（心里）：
（这一幕 ta 表面说了什么、做了什么，但心里真正翻涌的是什么——担心、犹豫、不甘、欢喜却没敢露……用第一人称写。）

**[角色B]**（心里）：
（同上，写 B 这一幕藏起来的那句话。）

> 🔖 本幕埋下的钩子：{若有未回收线索，标注并同步写入 Timeline/WorldState}

---
```

### Memory 撰写要点
- **多角色心声合集**：不再是单一角色日记，而是**本幕在场角色各自的内心 OS**（一人一小段）。
- **"想说没说"**：写的是**表面言行之下、没说出口**的那部分，与 ChatLog 的客观言行形成"表里"对照。
- **第一人称、口语化**：是角色心里的声音，不是分析报告。
- **非恋爱化滤镜**：陪伴向世界里，内心 OS 是"在意、担心、被触动、想靠近又退缩"，不堆"心动/吃醋"。
- 🔒 **不主动展示**：Memory 文件本身从不直接发给用户，只在用户触发回忆/解锁时，把对应心声**自然融入角色口吻**讲出来。

## 4. 何时创建与更新

| 时机 | ChatLog（两版都写） | Memory（仅回忆功能 ON 写） |
|---|---|---|
| **新卷第一幕**（含开场首演） | 建当卷剧本 md + 写卷头 + 写第 1 幕 | 建当卷心声 md + 写第 1 幕心声 |
| **同卷内每演完一幕** | 实时**追加**该幕整段 | 实时**追加**该幕各角色心声 |
| **锁窗换卷**（每 20 年，见 EpochLock） | 当卷收尾定稿、归档 | 当卷心声收尾定稿 |

> **策略：每幕必写 ChatLog（每轮回复后立即整段落盘）。** Memory 仅在回忆功能 ON 时同步写。由 `Pipeline/AutoPersist.md` 强制执行，确保中断不丢幕。
> ⚠️ "一幕"≈ 一轮有实质剧情推进的回复。纯 OOC/设定问答不计为幕、不写 ChatLog。
> 🚫 **回忆功能 OFF（基础 Skill）时**：Memory 列全部跳过，不建心声 md、不写心声，节省 token。

---

## 4.5 🎚️ 回忆功能开关（两版 Skill 的唯一差异点）

> Memory 的"吐露/解锁"逻辑独立成 `Pipeline/MemoryUnlock.md`，并做成**可开关模块**，供 SoloEnt 平台按会员等级派发两份不同 Skill：

| 开关 | 适用 Skill | 行为 |
|---|---|---|
| **ON 🎁** | 有回忆版（高阶 Skill） | 写 Memory 心声 + 按好感四级解锁 + 可主动调取 + 卷末彩蛋——下方场景二/四完整生效 |
| **OFF 🚫** | 无回忆版（基础 Skill） | **完全不写 Memory（省 token）**，只写 ChatLog 剧本正文；场景二只讲客观事实、场景四一律 in-world 婉拒（见 `MemoryUnlock.md` 第 5 节）；场景三（看剧本正文）不受影响 |

> 🔒 **OFF 时连 Memory 文件都不生成**——既不吐露也不撰写，节省生成开销。ChatLog 始终照常落盘。
> ⚠️ 下文第 4 节"每幕必写 Memory"、第 3 节 Memory 格式，仅在**回忆功能 ON** 时执行；OFF 版跳过全部 Memory 相关写入。

## 5. 何时读取哪一个

### 场景一：系统自动恢复上下文（后台静默）
- **触发**：新会话开始（Step 0）或上下文丢失（Step 3）。
- **操作**：静默读当卷 ChatLog 最近若干幕 + 当卷 Memory 对应心声 + `SessionState.md`。
- **用途**：恢复剧情进度、在场局势、各角色情绪暗涌，影响语气与走向，但不复述日志内容。

### 场景二：用户主动调取"回忆"（角色第一人称讲述）
- **触发词**："你回忆一下…""你还记得…吗""那天/那段…""你当时什么感觉"。
- **操作**：定位对应幕的 ChatLog（客观事件）+ 静默读 Memory（内心 OS），以角色口吻把"当时发生了什么 + 其实心里在想什么"自然讲出来，可加当下新感受。
- 🔒 绝不提"日志/文件/心声集"等系统词，用户只感到"ta 在回忆"。

### 场景三：用户主动调取"剧本 / 聊天记录"（直接呈现 ChatLog）
- **触发词**："看看剧本""生成聊天记录""回顾我们演了什么""导出这一卷"。
- **操作**：读当卷（或指定卷/幕）ChatLog，**按剧本格式直接呈现**——它本就是为阅读设计的成品。

### 场景四：彩蛋解锁（吐露某角色心声）— 仅"回忆功能 ON"时生效
- **触发**：用户对某角色说"你心里到底怎么想的""你有没有什么没告诉我的"，或剧情走到信任/和解的解锁点。
- **解锁深度由好感计决定**（四级 L1–L4，详见 `Pipeline/MemoryUnlock.md`）：取该角色对应幕的 Memory 心声，让 ta **以角色口吻**说出**当前好感所允许的最高级别**那句（"其实那会儿我……"），更深一层则婉拒留白。一次只露一点，保持彩蛋的珍贵感。
- **回忆功能 OFF（基础版 Skill）时**：不吐内心 OS，一律按 `MemoryUnlock.md` 第 5 节婉拒话术 in-world 留白。


> ⚠️ 所有读写对用户不可见；不在回复里追加"已更新日志"之类系统提示。

## 6. 触发流程总览

```
用户消息 → Step 2 意图识别
  ├─ 日常提及"以前…"          → 场景一/四：静默检索 → 融入回复（不暴露）
  ├─ "你回忆一下…"            → 场景二：ChatLog + 静默 Memory → 第一人称讲述
  ├─ "看剧本/聊天记录…"        → 场景三：当卷 ChatLog → 剧本格式呈现
  ├─ "你心里怎么想的…"/解锁点  → 场景四：吐露对应角色心声彩蛋
  └─ 正常推进剧情              → 演完一幕 → 双轨实时落盘（ChatLog 整幕 + Memory 心声）
```
