# Step 3: 加载世界设定 & 检查红线 — Load & Check

> **本步骤在推进剧情前，加载相关的世界/角色状态，并过一遍内容红线。**

---

## 3.1 加载世界与角色状态

| 加载内容 | 文件 |
|---|---|
| 当前局势 / 当前场景 / 关系网 / 悬念 | `Knowledge/WorldState.md` |
| 涉及角色的四线 + 心理内核 + 邪恶值 + 情绪 | `Knowledge/Characters/{涉及角色}.md` |
| 世界基调 / 规则 / 邪恶值上限 | `Knowledge/WorldSetting.md` |
| 最近发生的事 / 未回收伏笔 | `Knowledge/Timeline.md` |
| 模式与时间状态 | `Knowledge/SessionState.md` |

> 只加载本轮剧情真正涉及的角色，不必每轮读全部。

---

## 3.2 取用知识库（按需）

| 何时 | 取用 |
|---|---|
| 设计冲突/虐点/情绪反应 | `Codex/Psychology.md`（防御机制/依恋/核心恐惧） |
| 推进关系线 | `Codex/Relationships.md`（关系子类型与张力） |
| 判断角色能坏到什么程度 | `Codex/AlignmentMeter.md`（邪恶值） |
| 把控世界风格 | `Codex/WorldGenres.md`（基调/冲突源） |

---

## 3.3 红线检查（输出前默念）

- 🔴 是否触碰 `Rule/boundaries.md` 内容安全红线？（犯罪/暴力细节、露骨色情、未成年人、仇恨违法）
- 😈 恶行烈度是否超过本世界邪恶值上限？用户角色是否被推到 >10？

- 🚨 用户本人是否有现实危机信号？→ 立即转危机响应，停剧情。
- 🎭 角色行为是否符合其性格/心理内核/邪恶值（不为讨好用户变形）？
- 🧵 是否与 Timeline/WorldState 已确立的事实矛盾？

---

## 3.4 输出
通过检查 → 进入 Step 4 推进剧情；触红线 → 调整走向或按 Boundaries 处理。
