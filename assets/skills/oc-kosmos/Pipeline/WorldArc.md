# 📊 世界总时长 & 暗进度条 — World Arc

> **本文件定义世界的"宏观剧情节奏"：开局必选的世界总时长，以及一条后台暗进度条，用来把控大主线何时铺垫、何时引爆、何时收束。**
> 🔒 **暗进度条与一切节奏术语永不展示给用户**（受 `Rule/hide-thinking.md` 黑名单约束）。用户只感受到"故事有起承转合"，而看不到任何数字或节点名。

---

## 1. 世界总时长（开局必选项）

> 这是开局"必选三件套"之一（另两项见 `Pipeline/Step1_StateCheck.md`：①一句话世界观 ②观察/下场）。**必须问，不能跳过。**

| 选项 | 世界跨度 | 适合 |
|---|---|---|
| **一年** | 一年内的完整故事 | 短篇、强情节、快收束 |
| **十年** | 十年成长史 | 中篇、人物成长、世代感初现 |
| **五十年** | 半个世纪 | 长篇、跨代、格局变迁 |
| **一百年** | 一个世纪 | 史诗、家族/王朝兴衰 |
| **无限** | 没有终点 | 永续经营、养成、世界长跑 |

- 选定后写入 `WorldState.md → 世界总时长`（🔒 后台字段）。
- 用世界观语言问，不要列成"请选择世界时长 1/2/3"。示例（古代）："这出戏，你是想看它一年里就唱完，还是要它跨个十年、五十年，甚至传成百年的老故事？或者——就让它一直唱下去？"

---

## 2. 暗进度条结构（🔒 永不展示）

为每个世界在后台维护一条 **0% → 100%** 的主进度条，映射五大宏观节点：

| 进度 | 宏观节点 | 该阶段世界该做什么 |
|---|---|---|
| 0–15% | **开端** | 立人物、立日常、立"想要的东西"，让用户认识这个世界 |
| 15–40% | **铺垫** | 埋矛盾、起波澜、积累情绪与张力，扳机开始上膛 |
| 40–70% | **发展** | 矛盾升级、阵营/关系激化、若干中型转折，主线逼近临界 |
| 70–90% | **高潮** | 大主线扳机进入"用户可扣动"区，重大抉择与爆发集中发生 |
| 90–100% | **收束** | 余波、结局、各线收尾（有限世界走到此即大结局） |

> 🔴 节点名（开端/铺垫/高潮…）、百分比、"进度条"三个字——**全部只存后台，绝不出现在输出里**。

---

## 3. 进度条怎么走（推进规则）

- **驱动来源**：用户每次在场推进剧情（Step 4）+ 缺席期补全（TimeAdvance）都会让进度按世界内时间占比前移。
- **占比换算**：`进度% ≈ 已流逝世界时间 ÷ 世界总时长`（无限世界见第 5 节，不按此换算）。
- **节奏调速**：Agent 用进度条判断"现在该克制还是该放料"：
  - 进度落后于精彩度（世界太平淡）→ 提前埋矛盾、加快铺垫。
  - 进度临近 70%+ → 开始把大主线扳机往用户面前递（但仍遵守"缺席期不动主线"，扳机只在用户在场时由 `ChoiceBranch.md` 交出）。

---

## 4. 大主线扳机的"递出"判定

> 进度条最重要的职责：决定**何时把"影响世界主线走向的大事件"交给用户决定**。

| 进度区间 | 大主线扳机 |
|---|---|
| < 40% | **不递**（只铺垫，太早引爆会泄气） |
| 40–70% | **小扳机**：中型转折可由用户在场触发 |
| 70–90% | **大扳机**：核心主线抉择集中递出，用户在场时由四选项交出定夺权 |
| 90–100% | **收束扳机**：导向结局的最终抉择 |

- 与 `Pipeline/TimeAdvance.md` 4.0 节联动：缺席期把扳机"擦亮悬停"，用户在场时进度条决定"这一把能不能扣"。
- 与 `Pipeline/ChoiceBranch.md` 联动：到高潮区，四选项里至少有一个是"大主线级"走向。

---

## 5. 与纪元锁窗（EpochLock）的关系

> 进度条管"宏观节奏"，锁窗管"按 20 年物理分卷"，两者正交、并存。

| 世界总时长 | 锁窗行为 | 进度条行为 |
|---|---|---|
| ≤ 20 年（一年/十年） | 期间不锁窗 | 进度走满 100% → **大结局收束** |
| > 20 年（五十年/一百年） | 每满 20 年锁窗分卷（见 `Pipeline/EpochLock.md`） | 进度跨多卷累计，最终走满 → 大结局 |
| 无限 | 每满 20 年锁窗分卷 | **不设 100% 终点**；进度条改为"每卷内部 0–100%"循环，每卷自有起承转合，但世界无最终结局 |

## 6. 落盘字段（🔒 写入 State 文件）

| 文件 | 字段 |
|---|---|
| `Knowledge/WorldState.md` | `世界总时长`、`暗进度条 %`、`当前宏观节点`（均标 🔒） |
| `Knowledge/SessionState.md` | 同步 `暗进度条 %`、`当前宏观节点` 便于跨会话续推 |

> 🔴 这些字段是 Agent 的"导演手记"，对用户绝对不可见，连"我正在推进世界进度"这种话都不能说。
