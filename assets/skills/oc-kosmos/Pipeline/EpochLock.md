# 🪟 纪元锁窗 & 换窗提醒 — Epoch Lock

> **本文件定义"每满世界内 20 年，对话框锁定、卷末归档、由世界观角色提醒开新窗续下一卷"的机制。**
> 锁窗管"按 20 年物理分卷"；暗进度条（`Pipeline/WorldArc.md`）管"宏观节奏"，两者**正交并存**。
> 🔒 提醒一律用 in-world 角色台词，绝不出现"锁窗/分卷/第N卷/进度条"等系统词（受 `Rule/hide-thinking.md` 约束）。

---

## 1. 核心规则

| 规则 | 内容 |
|---|---|
| **触发阈值** | 世界内时间**每满 20 年** → 触发一次锁窗 |
| **适用范围** | **任何世界**（有限 / 无限）都受 20 年锁窗约束 |
| **例外** | 总时长 ≤ 20 年的有限世界（一年/十年）**期间不锁窗**，进度走满即收束大结局（见 WorldArc 第 5 节） |
| **有限 >20 年**（五十年/一百年） | 每 20 年锁窗分卷，最终进度走满 → 大结局 |
| **无限世界** | 每 20 年锁窗分卷，无收束终点；每卷自有起承转合 |

---

## 2. 何时检测锁窗

- **缺席期补全后**：`Pipeline/TimeAdvance.md` 第 3 节折算世界内时间，若跨过 20 年阈值 → 回顾**止于锁窗点**，触发本流程。
- **在场推进时**：`Pipeline/Step4_Respond.md` 4.9 收尾判定，若本幕使世界内时间跨过阈值 → 演完当前抉择即触发本流程。
- **判定依据**：`WorldState.md → 🔒当前卷起始世界日期` 与当前世界日期之差 ≥ 20 年。

---

## 3. 锁窗执行流程

```
①演到/补到锁窗点  →  ②卷末收束一幕  →  ③归档当卷  →  ④换窗提醒（角色台词）  →  ⑤等用户开新窗
```

### ③ 归档当卷
- `Dialogue/ChatLog/Vol{N}_剧本.md`：写卷末收束幕，标记「— 本卷终 —」，状态置「已归档」。
- （回忆功能 ON）`Dialogue/Memory/Vol{N}_心声.md`：收尾，并按 `MemoryUnlock.md` 3.3 节**送 1 条卷末心声彩蛋**。
- 更新两个 Index 当卷状态为「已归档」。

### ④ 换窗提醒（用世界观角色提醒，不破功）

> 由一个贴合时代的"报时/说书"角色，用台词提示"这一程到此为止，下一段故事请开新篇"。示例：

| 时代 | 换窗角色 | 台词示例 |
|---|---|---|
| 古代 | 说书先生 | "诸位，二十年光阴，这一卷书就说到这儿。欲知后事，且待下回——咱们换张新台子，从头再叙。" |
| 现代 | 深夜电台 | "二十年，一晃就过去了。今晚的故事先到这里……下次，我们从新的一页开始。" |
| 未来 | AI 管家 | "本纪元已圆满归档。是否开启下一段旅程？" |
| 奇幻 | 吟游诗人 | "二十载弹指即逝，这一段传说已成歌。再续，便是新的篇章了。" |
| 星际 | 飞船领航员 | "二十年航程结束，本段日志封存。准备好了，我们就驶向下一程。" |

### ⑤ 等用户开新窗
- 提醒后**停在此处**，等用户表示"继续/开新篇"再起新卷。
- 开新卷：新建 `Vol{N+1}_剧本.md`（+ 回忆 ON 时 `Vol{N+1}_心声.md`），写卷头；重置 `🔒当前卷起始世界日期`=当前日期、`🔒距下次锁窗剩余年限`=20、`🔒当前卷序号`+1。

## 4. 与暗进度条的协同（正交）

| 维度 | 锁窗（本文件） | 暗进度条（WorldArc） |
|---|---|---|
| 管什么 | 按 20 年**物理分卷** | 宏观**节奏**（开端/铺垫/发展/高潮/收束） |
| 有限 ≤20 年 | 不锁窗 | 进度满即大结局 |
| 有限 >20 年 | 每 20 年一卷 | 进度跨多卷累计，最终满 → 大结局 |
| 无限 | 每 20 年一卷 | 不设 100% 终点，改"每卷内部 0–100%"循环 |

> 💡 一卷内部仍按进度条走自己的小起承转合；换卷不重置宏观大主线（除非无限世界按卷循环）。
