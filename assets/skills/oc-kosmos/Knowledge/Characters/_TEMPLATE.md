# 🪪 角色卡模板 — Character Sheet Template

> **复制本模板生成每个角色，文件名用角色名（如 `林深.md`）。**
> **建角色时取用 `Codex/` 知识库：人格(Psychology) + 关系(Relationships) + 邪恶值(AlignmentMeter) + 世界基调(WorldGenres)。**
> **每条线、每个属性都要"有根"，彼此自洽，不要拼贴矛盾标签。**

---

## 🔑 可见性分层总则（必读）

本卡分两层，Agent 必须严格区分：

| 层 | 标记 | 含义 | 用户能否看到 |
|---|---|---|---|
| **公开层** | 🟢 | "认识一个人会知道的东西"——外貌、说话方式、明面身份与关系、明面目标 | ✅ 可见（用户请求看角色时，按 `Pipeline/CharacterReveal.md` 渲染） |
| **后台层** | 🔒 | 创作侧标签 + 心理根因 + 数值 + 剧透 + 内心 OS | ❌ **永不输出**，仅供 Agent 内部决定角色"怎么反应" |

> ⚠️ 🔒 层内容受 `Rule/hide-thinking.md`「创作元语言黑名单」约束：即使用户追问，也只能用行为表现，绝不报标签/数值/剧透。

---

# 🟢 公开层（用户可见 — 一个人初识时能感知到的）

## 一、基本信息 🟢
- **姓名**：
- **年龄 / 性别**：
- **身份 / 职业**：（明面上的，对外公开的身份）
- **一句话人设**：（用户读得到的那种，不含创作术语）
- **外貌标志**：（一两个能看见画面的细节）

## 二、🎭 性格表达（怎么说话、怎么反应）🟢
- **说话风格 / 口头禅**：
- **明显的脾气/习惯**：（旁人相处一阵就能察觉的，如"爱抬杠""话少但靠谱"）
- **怪癖 / 标志物**：（看得见的外在特征，不解释成因）

## 三、🤝 明面关系与目标 🟢
- **明面关系**：（公开的、人尽皆知的关系，如"是 A 的师兄""开着城东那家茶馆"）
- **明面目标**：（ta自己会对外说出口的追求，如"想把生意做大""想考取功名"）

# 🔒 后台层（仅 Agent 可见 — 永不输出给用户）

> 🔒 以下全部内容**绝不出现在任何用户可见文本中**。它们是 Agent 决定角色行为的"幕后引擎"，只能通过"角色怎么做"来间接体现。

## 四、🧠 心理内核 🔒（取自 `Codex/Psychology.md`）
- **人格模型**：（九型 / MBTI / 大五）
- **核心欲望 / 核心恐惧**：（= 驱动力 / 软肋）
- **依恋类型**：（安全 / 焦虑 / 回避 / 恐惧）
- **主要防御机制**：（受伤时的真实反应方式）
- **错误信念 / 伤口**：（成长要挑战的那句话，如"我不配被爱"）
- **原生家庭底色**：（童年脚本 / 创伤）

> 🔒 用法：决定 ta 在亲密/受伤/受威胁时"怎么反应"。**只表现，不标注。**

## 五、😈 邪恶值 🔒（取自 `Codex/AlignmentMeter.md`）
- **当前邪恶值**：[0–10 常规 / 11–25 仅悬疑犯罪世界的NPC反派]
- **道德底线**：（ta绝不会做的事 / ta会做的最坏的事）

> 🔒 用法：决定 ta 行为的恶意上限。**用行为体现狠到什么程度，不报数值。**

## 六、🧵 剧情线 🔒（取自 `Pipeline/StorylineWeave.md`）

### 🎯 主线（命运线）
- 长期目标 / 当前进度 / 下一个里程碑 / 阻碍·反派·代价 / 关联角色：

### 🌱 成长线（内在弧光）
- 要挑战的错误信念 / 当前状态 / 下一个转变契机：

### 💼 事业线
- 目标·当前阶段 / 对手·机遇·挫败 / 下一个里程碑：

### 🏠 家庭线
- 家庭构成·关键关系 / 当前张力 / 下一个里程碑：

### ❤️ 情感线（关系/羁绊）
- 与谁·关系类型（取自 `Codex/Relationships.md`）/ 当前阶段 / 张力·虐点来源 / 下一个里程碑：

> 🔒 用法：决定剧情往哪走。**用情节推进体现，不报"这是XX线里程碑"。**

## 七、💢 情绪状态 🔒（取自 `Pipeline/EmotionSim.md`，系统实时维护）
- 喜/乐：平稳 ｜ 怒：无 ｜ 哀：无 ｜ 压力：一般
- 对各重要角色的好感：（角色名 → 档位/数值）
- 与各角色的矛盾积累：（角色名 → 0–满）

## 八、🃏 暗面与剧透 🔒
- **隐藏身世 / 秘密**：（如"被协会捡到的弃婴"——只存这里，剧情靠行为暗示）
- **未公开的暗线**：（ta身上尚未揭晓的伏笔）
- **没说出口的内心 OS**：（彩蛋素材，供 `Dialogue/Memory/` 与回忆解锁使用）
