# 中文标点规范（正文强制）

`scripts/fix_punctuation.py` 已在导出流程中自动执行第 1–4 条的机械部分。本文档用于第三步复查，以及作者手改时对照。

## 1. 引号必须使用方向性字符

**绝对禁止**直引号 `'`（U+0027）和 `"`（U+0022）。

| 类型 | 左（开始） | 右（结束） |
| :--- | :--- | :--- |
| 单引号 | `‘` (U+2018) | `’` (U+2019) |
| 双引号 | `“` (U+201C) | `”` (U+201D) |

- 引号前为空白 / 段首 / 左括号 / 冒号 / 逗号 / 其他左引号 → 左引号
- 引号前为字、词或句末标点 → 右引号
- 撇号（`it’s`、`John’s`）一律用 `’`

脚本按前一个字符猜方向，**嵌套引语和跨段引语会猜错**，对话密集的段落必须人工核对开闭配对。

## 2. 中文正文使用全角标点

主语种为中文的段落，标点全部用全角：`。，、；：？！“”‘’（）《》`，省略号 `……`，破折号 `——`。

**例外保留半角**：嵌入的英文原词、数字（3.14、1,000、3:15）、文件名、网址。

## 3. 顿号与逗号（脚本判断不了，必须人工）

并列的词或短语之间用顿号 `、`，不用逗号：

- ✗ 刀，剑，枪，戟，样样精通
- ✓ 刀、剑、枪、戟，样样精通

并列的**分句**之间仍用逗号或分号。

## 4. 书名号（脚本判断不了，必须人工）

正文中提到的书名、篇名、功法秘籍名、歌曲名加 `《 》`，书名内再套用 `〈 〉`。

## 5. 正文禁止任何 Markdown 标记

番茄正文框是纯文本，`**` `*` `#` `>` `-` 会原样显示成乱码般的符号。

- 禁止：加粗、斜体、删除线、标题井号、引用符、列表符号、分节符、行内代码
- 强调靠断句和短段落，不靠符号
- 章节标题只在**独立一行**出现，不加任何符号

## 6. 排版（番茄读者的阅读习惯）

- 一行一句，两三句一段；手机屏上一段占不过半屏
- 段落之间**不空行**，番茄编辑器会自动处理段间距
- 段首**不加空格**，编辑器自动首行缩进；手工加的全角空格会变成多余留白
- 对话单独成段，不和叙述挤在一段里

## 7. 场景分隔

原稿里用 `---`、`***`、`* * *` 做的场景切换，导出时会被删除（它们是 Markdown 标记）。需要保留切换感时，改写成一句时间或空间的过渡文字，例如「三天后。」「与此同时，城东。」

## 8. 复查后重跑

```bash
python3 scripts/export_fanqie_txt.py 正文目录/ --book "书名" --check
```

```powershell
powershell -ExecutionPolicy Bypass -File scripts\export_fanqie_txt.ps1 -Book "书名" -Check 正文目录\
```

退出码 0 表示自检项全部干净。

只想单独修标点、不导出 txt 时，用标点脚本本身：

```bash
python3 scripts/fix_punctuation.py --check 文件...    # 看改动
python3 scripts/fix_punctuation.py 文件...            # 就地修复
```

```powershell
powershell -ExecutionPolicy Bypass -File scripts\fix_punctuation.ps1 -Check 文件...
powershell -ExecutionPolicy Bypass -File scripts\fix_punctuation.ps1 文件...
```
