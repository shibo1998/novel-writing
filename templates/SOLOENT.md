## 各部分更新频率与责任

| 部分 | 更新频率 | 谁更新 |
|---|---|---|
| 1. 项目 DNA | 初始化时一次 | 用户（很少改） |
| 2. 世界系统 | 世界扩展时 | agent + 用户 |
| 3. 角色 | 添加角色时 | agent + 用户 |
| 4. 情节与结构 | 大纲更改时 | 用户 |
| 5. 风格指南 | 需要纠正风格时 | 用户 |
| 6. 关键约束 | 修订后 + 随时 | **agent（从反馈学习）+ 用户** |
| 7. 活跃写作状态 | **每章后** | agent（自动） |
| 8. 路线图 | 任务完成时 | agent（自动） |

> ⚠️ **让第 7 部分过时是最常见的陷阱。** 你写了 3 章却没更新状态，
> AI 就会在你实际写到第 8 章时写得像还在第 2 章。
> 本插件用 `.soloent/memory/now.md` 的状态块 + 出章闸门强制这一条。
