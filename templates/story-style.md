# 本书风格规则（最高优先级）

> 与其他规则冲突时**以本书为准**。本文件只放**本书专属**内容；
> 通用规则（去 AI 味 4 条、网文基础、题材规则）由 `AGENTS.md §2` 声明加载清单，
> 不在这里复制，避免多份同步。

## 一、题材与定位

- ✏️题材 / 读者画像 / 平台
- ✏️本书的核心爽点与阅读承诺

## 二、叙述人称与视角

- ✏️人称、视角纪律（如：有限视角只写人物能看见、听见、猜到或误判的内容，不替读者解释意义）

## 三、节奏与篇幅

### 3.1 句长节奏（分轨）

> ⚠️ 阈值**必须来自样板书实测**，不能凭空拍。
> 教训：初版用「整章平均句长」做指标，结果在惩罚对话的存在——对话天然短，
> 40% 对话的章节怎么改都到不了线，还掩盖了真问题：叙述句本身也偏短。
> 现改为叙述与对话**各算各的**，对话另设占比上限。

| 指标 | 下限/上限 | 本书取值 | 样板书实测 |
|---|---|---|---|
| 叙述句平均句长 | ≥ | ✏️22 | |
| 叙述长句(>25字)占比 | ≥ | ✏️25% | |
| ≤10字短句占叙述句 | ≤ | ✏️25% | |
| 对话占全章 | ≤ | ✏️55% | |
| 转折/关联词密度 | ≥ | ✏️7.0/千字 | |

> 上面这张表要同步到 `.soloent/book.json` 的 `checks.rhythm`。
> **怎么定阈值**：跑 `python tools/consistency_check.py --suggest-rhythm`
> —— 它按实测算出各项分位并给出可直接粘贴进 `book.json` 的取值（与机检同一套口径）。
> 有样板书时把原文放进 `1-边界/` 再跑 `--suggest-rhythm --from 1-边界`，结果更可信。


### 3.2 清单体禁令

✏️（如：「传功堂。六块灵石。三年一回。」这类成串的名词/数字短句连着用即清单体；
每句都砸一下就没有重锤了。）

### 3.3 段落

✏️（短段为主，一两句成段；关键互动展开成完整对手戏段落，普通过场压短段。）

## 四、语言

- ✏️口语化程度、用词偏好
- **别经常用生僻字或词**（判断标准是「普通读者认不认识」，不是语料频率高低）
- ✏️本书特有的用词禁令

## 五、人味（每章自检）

✏️每章至少要有两处「没用」的东西——不推动情节、不交代信息，纯粹是人的毛边。
（如：一个没意义的小动作、一句答非所问、一个与主线无关的偏好。）

> 这条是**正向工艺规则**，不是禁令——它是「像人写的」最直接的抓手。

## 六、红线

- ✏️（人物不能崩的定位、不能提前揭的情报、不能违背的世界规则）
