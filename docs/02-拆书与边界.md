# 02 · 拆书与边界

> ★ **进本阶段前，先做一件事：回看 `1-边界/预期.md`。**
> 那是开新书时你自己写的"想写什么、不想写什么、为什么写这本"。
> **拆书很容易被样板书带跑**——看什么好就想往那个方向靠。先确认边界，再拆。

> **有对标作品时强烈建议先做这一步。** 它把"我想写得像 XX"变成可执行的写作边界，
> 后面每一步都有参照物，而不是凭感觉。

## 用什么技能

`assets/skills/wuhang-long-chaijie2/`（武行·样板书拆解 2.0）——专做样板书拆解，
比全流程里那版更新。读它的 `SKILL.md` 按流程执行。

另有 `assets/skills/wuhang-long-all/1-边界确定/SKILL.md` 是全流程的边界模块。

## 样板书怎么准备

1. 把样板书正文（txt / md）放进 `1-边界/`
2. 提取章节用**本地修正版脚本**（原版有已知问题）：

```bash
# 若项目里有 _tools/extract.py（修正版），优先用它
python _tools/extract.py "1-边界/凡人-《凡人修仙传》.txt" 1 5      # 读第 1–5 章
python _tools/extract.py "1-边界/凡人-《凡人修仙传》.txt" --list   # 导出章节目录
```

原版 `extract_chapters.py` 的三个已知问题（修正版已解决）：
1. 编码硬编码 utf-8 —— GB18030 的样板书直接读取失败；
2. 「第X卷」卷标题行被计为章节 —— 全书章号整体错位；
3. 章节标题行连续出现两次 —— 重复计数。

## 拆什么

拆解的目的是**产出写作边界**，不是写读书笔记。重点拆四样：

| 拆什么 | 产出 | 后面谁用 |
|---|---|---|
| **开篇** | 前 3 章做了什么、每章结尾钩子长什么样 | 写自己的开篇时对照 |
| **节奏** | 单章字数、场景数、对话占比、句长分布 | 填 `book.json` 的 `checks.rhythm`（**阈值必须实测，不能凭空拍**） |
| **文风** | 人称、视角纪律、用词习惯、口语化程度 | 写进 `.soloent/rules/story-style.md` |
| **结构** | 卷/章的组织方式、爽点密度、升级节奏 | 写总纲与卷纲时对照 |

## 关键纪律

- **边界拆解是参考素材，不是正典。** 写进 `1-边界/` 的东西**不得作为剧情正典引用**。
  它是"别人怎么写的"，不是"我的书里发生了什么"。
- **节奏阈值必须实测。** 教训：曾用"整章平均句长"做指标，结果在惩罚对话的存在——
  对话天然短，40% 对话的章节怎么改都到不了线，还掩盖了真问题（叙述句本身也偏短）。
  正确做法是**分轨**：叙述与对话各算各的，对话另设占比上限。
- **别把频率测试用过头。** 曾按语料频率一刀切把「埂/畦/锹/褐」列为生僻字，
  但那是正常词——样板书不写它们，只是因为不种地。判断标准是**普通读者认不认识**，
  不是语料频率高低。

## 产出落到哪

```
1-边界/
├── <样板书>.txt                   原件
├── 1.1_开篇拆解.md
├── 1.2_文风.md                    ← 会被正文阶段直接引用
├── 1.3_节奏.md
├── 1.4_结构.md
├── 1.5_微观节奏拆解.md             （可选：场景调度/镜头语言）
└── 横向对比报告.md                 拆多本时才有
```

拆完把 `1.2_文风.md` 的结论提炼进 `.soloent/rules/story-style.md`（本书规则，优先级最高），
把节奏阈值填进 `book.json` 的 `checks.rhythm`。

## 拆书产物会被闸门检查（2026-09-20 起）

- **判据**：`1-边界/` 下要有 `1.1_开篇拆解.md` 这类产物（命名约定：序号_名称，两个数字用点分开）。
- **什么时候拦**：`1-边界/预期.md` 里**声明了对标作品**（那一行含「对标」且后面有实质内容），
  而 `1-边界/` 下没有任何拆书产物 → `tools/brief.py` 拦下每一章，`doctor.py` 报警。
  实测踩过：某书预期里写着「对标《我有一座冒险屋》的钩子密度 +《全球高武》的数值纪律」，
  `1-边界/` 却空空如也，书一路写到 69 章——对标停在口号层，写出来自然是「平均值」。
- **真不需要拆时**：在 `.soloent/book.json` 的 `boundary.opt_out_reason` 写明理由即可放行。
  **要的是一次明确决定，不是硬卡**（没声明对标的书本来就只提醒不拦）。
- **拆完顺手校准节奏**：把样板书原文放进 `1-边界/`（或任意目录），跑
  `python tools/consistency_check.py --suggest-rhythm --from 1-边界`，
  它会给出可直接粘贴进 `book.json` 的 `checks.rhythm` 阈值（与机检同一套口径）。
