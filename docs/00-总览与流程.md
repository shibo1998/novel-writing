# 00 · 总览与流程地图

## 全流程

```
① 初始化          建文件夹、写配置、生成 AGENTS.md 与 tools/
     ↓
② 拆书与边界      （有样板书时）拆开篇/节奏/文风 → 1-边界/
     ↓
③ 世界观与设定    世界观、力量体系、金手指、角色、宪法
     ↓  ← 力量体系定下来后，回头把 book.json 的机检项与账本结构补上
④ 大纲            总纲 → 卷纲
     ↓
⑤ 细纲            章纲（逐章：节拍、钩子、涉及伏笔）
     ↓
⑥ 正文            每章循环：接地 → 起草 → 自查 → 三连 → 复查 → 回写 → 过闸 → 质量审查
     ↓
⑦ 审查与修订      每章质量审查（正文第 7 步）＋ 卷末/阶段回溯；单章问题回到对应阶段修
```

**阶段 ② 可跳，③④⑤ 不可跳**——它们不是四个独立开关，而是一条链（见下）。
**每章循环里只有第 1 步（起草）可调**：第 0 步接地、第 2–5 步（自查／三连／复查／回写）、
第 6 步过闸、第 7 步质量审查**全部强制**，且第 5 步的流程留痕行会被闸门校验。

## 正式章节与探索草稿的边界

| | 正式章节 | 探索草稿（`tools/draft.py`） |
|---|---|---|
| 位置 | `chapters/ch-N.md` | `drafts/`（头部标 **NON-CANONICAL／非正典**） |
| 前置要求 | 正典无占位、本章细纲、账本行齐全，缺一 `brief.py` 即拦截 | 无——想法随时可落 |
| 状态与账本 | 推进 `now.md`、写 `ledger.tsv`、占章号 | 全部不动 |
| 闸门 | `preflight.py` 必查 | 不检查，也**不允许**被它当正文 |

草稿转正只有一条路：补齐正典 + 细纲 + 账本行 → 作者确认 → 另存为
`chapters/ch-N.md` → 走完整的每章循环过闸。**没有「试写稿直接当第 1 章」的旁门。**

> **两个关 ＋ 四步工艺**：闸门（第 6 步）清的是算得出来的硬伤；
> 质量审查（第 7 步）管的是机检看不见的 AI 句式、人味与钩子；
> 第 2／3／4 步（句法自查／技能三连／连续性复查）是这条防线上的常驻工序。
> **只过闸门 = 只过了一半的关。** 详见 `06-正文.md`。

## 阶段依赖：为什么 ③④⑤ 不能跳

| 阶段 | 能否跳过 | 依据 |
|---|---|---|
| ② 拆书与边界 | **可跳**（有对标作品时强烈建议做） | 产出是"参照物"（文风／节奏／结构），下游靠它**校准**，不靠它取数 |
| ③ 世界观与设定 | **不可跳** | 产出 `canon.md`（每章 B1 接地的**值来源**）＋ `world/` `characters/`（B5 复查的**比对对象**） |
| ④ 大纲 | **不可跳** | 产出「伏笔回收总表」——**`brief.py` 的输入之一**（`docs/04`） |
| ⑤ 细纲 | **不可跳** | 产出章纲（每章节拍／钩子／伏笔）——**`brief.py` 的唯一节拍来源**（`docs/05`） |

链是这样接的：

```
③ canon.md / world/ / characters/  →  每章 B1 接地（强制）取值 + B5 复查比对
④ 伏笔回收总表                      →  brief.py 筛出"本章该埋／该接／该爆"
⑤ 章纲（节拍／钩子）                 →  brief.py 拼出本章接地单
                                            ↓
                          每章第 0 步（强制）读的就是这张接地单
```

**所以 ③④⑤ 缺任何一环，每章的强制第 0 步就是空转**——接地单拿不到节拍、拿不到伏笔，
「照着事实写」就退化回「凭印象写」。这正是 2026-09-18 之前那批章节漂移的成因。

`docs/04` 原话：「**顺序不能反。** 先定总纲，再切卷，最后才逐章。反过来会写着写着发现结构塌了。」

> **② 与 ③④⑤ 的区别**：② 决定「往哪个方向写」（风格边界），③④⑤ 决定「写什么」（事实与结构）。
> 方向可以边写边调，**事实和结构不行**——它们一错，后面几十章都在错的账上走。

### 与武行原版（`wuhang-long-all`）的对应

本项目的阶段划分比灵蟹原版**细一档**，对照关系如下（避免两边教程混读时对不上号）：

| 本项目 | 武行原版 |
|---|---|
| ② 拆书与边界 | 第一步 `1-边界确定` |
| ③ 世界观与设定 | 第二步 `2-创意与设定` |
| ④ 大纲（总纲→卷纲） | 第四步 `3-大纲`（原版**总纲/卷纲/章纲一起做**） |
| ⑤ 细纲（章纲） | ↑ 同上，本项目把「章纲」单独拆出来 |
| ⑥ 正文（每章循环） | 第六步 `4-正文` ＋ 第七步 `5-审查` |
| ⑦ 审查与修订 | 第三/第五步的可选审查 ＋ 卷末回溯 |

> ⚠️ **两个「7」别混**：本页 `⑦` 是**阶段编号**（审查与修订这个阶段），
> `06-正文.md` 的「第 7 步」是**每章循环里的步骤**（质量审查）。两者不是一回事。

| ③ | **正典速查表**（值的事实来源） | `.soloent/canon.md` |
| ④ | 总纲、卷纲 | `outline/` |
| ⑤ | 章纲（细纲）、伏笔回收总表 | `outline/` |
| ⑥ | 章节正文、进度、账本 | `chapters/`、`.soloent/memory/now.md`、`.soloent/ledger.tsv` |
| ⑦ | 对账报告、诊断、废稿归档 | `notes/` |

**每个阶段完成后，都要把摘要回写进 `SOLOENT.md` 的对应板块**（见下）。

## 四层「单一来源」，不要搞混

| 单一来源 | 管什么 | 谁读它 |
|---|---|---|
| **`SOLOENT.md`** | **中央控制面板**（8 板块）：身份、约束、**全部文件指针**、当前进度摘要 | agent 每次开工先读它 |
| `.soloent/canon.md` | **值**：人名怎么写、数值多少、时间锚点、锁定细节 | agent 写正文前读；机检对照 |
| `.soloent/book.json` | **机器可读**的同一批值（机检项、账本列、规则清单） | 工具读 |
| `.soloent/ledger.tsv` | 逐章的数值事实 | 账本工具读 |

> ⚠️ `canon.md` 与 `book.json` 描述的是同一批事实，**改一处必须同步另一处**。
> 两处不一致 = 机制失效（不是"工具报错"，是"它以为的和你以为的不是一回事"）。

### SOLOENT.md 与各文件的对应

```
SOLOENT.md                    ← 中央面板：摘要 + 指针
├── §1 项目 DNA              → book.json 的 book 段（机器）
├── §2 世界系统              → world/*.md
├── §3 角色                  → characters/*.md
├── §4 情节与结构            → outline/*.md
├── §5 风格指南              → .soloent/rules/story-style.md
├── §6 关键约束              → .soloent/canon.md（值）+ book.json 的 checks（机器）
├── §7 活跃写作状态          → .soloent/memory/now.md（详细版）
└── §8 路线图                → .soloent/memory/roadmap.md（详细版）
```

**铁律：摘要留 SOLOENT.md，细节存分档。** 不要把世界观正文粘进中央面板——
那会让它臃肿到读不动，而它本该是每次开工都读一遍的东西。

## 什么时候该回头补 `book.json`

初始化的 `book.json` 是**刻意从简**的（正典机检项全空、账本只有 `ch/day/note` 三列）。
它是随写作**逐步长出**的：

| 触发点 | 该补什么 |
|---|---|
| 力量体系定案 | `checks.scale`（评级刻度）、`ledger.rank_order`（境界阶梯） |
| 确定了每日收益/升级成本 | `ledger.rank_costs`、`ledger.income` |
| 正文第一次写死某个专有细节（地点、物名、名讳） | `checks.locked_details`（当章登记） |
| 出现"这件事到第 N 章才能揭" | `checks.gated_keywords` |
| 发现某章数值/时间对不上 | `ledger.balance`（平账）、`ledger.anchors`（锚点） |
| 开始有稳定的文风问题 | `checks.rhythm`（句长节奏，阈值要从样板书实测来） |

补完跑一次：`python "<插件>/scripts/sync.py" --root "<书目录>"`
（只是让 `AGENTS.md` 里的规则清单刷新；工具本身读 `book.json`，立即生效）。
