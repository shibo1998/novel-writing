# 06 · 正文（每章循环）

> 这是最常走的一条路。**只有第 1 步（起草）是可调的，其余全部强制。**
> 依据：闸门能验的只有「算得出来的东西」，**AI 句式结构、人味、钩子质量全靠 2／3／4／7 四步**。

```
0. 接地（强制）
      ↓
1. 起草  →  2. 句法自查（强制）→  3. 技能三连（强制）→  4. 连续性复查（强制）
                                                              ↓
     8. 停下等确认  ←  7. 质量审查（强制）  ←  6. 出章闸门（强制）  ←  5. 收尾回写（强制·含流程留痕）
```

---

## 0. 接地（强制）

**读 `.soloent/canon.md`** —— 关键值一律从该表取，**不凭印象**。

然后跑接地单：

```bash
python tools/brief.py          # 下一章
python tools/brief.py 31       # 指定第 31 章
```

它会一次打出五节：
1. **细纲节拍** —— 本章标题、内容、章末钩子
2. **本章数值台账** —— 账本里这一行 + 上一章余额 + 平账提示
3. **相关伏笔三态** —— 本章该埋/接/爆的伏笔
4. **当前进度** —— `now.md` 状态块
5. **正典速查** —— `canon.md` 指定章节的摘录

**开工前先口述复述当前状态与本章任务，再动笔。**
「记忆丢失」通常不是忘了，是没去看。

---

## 1. 起草

- 按细纲的本章节拍码字，**严格遵守剧情范围，不得超出**。
- 单章字数服从 `book.json` 的 `chapter` 设定（默认约 2400 字，常态 2200–2600）。
- 分场景推进。
- **章末必须收在悬念、动作或未尽对话上**——禁止说教与升华。

### 写作时的硬性要求

| 项 | 要求 |
|---|---|
| 标点 | 中文全角；对话一律用中文双引号（“ ”），**严禁直角引号「」** |
| 视角 | 有限视角只写人物能看见、听见、猜到或误判的内容，**不替读者解释意义** |
| 心理 | 禁读心式直述（「他心里想」）与「一股XX涌上心头」式套路心理 |
| 用字 | 别经常用生僻字或词——判断标准是**普通读者认不认识**，不是语料频率 |
| 章标题 | 按 `book.json` 的 `chapter.title_regex`（默认 `# 第0XX章 标题`） |

---

## 2. 句法自查（强制）

按 `assets/rules/ai-anti-patterns.md` 的词表**逐条过一遍**，违规即改。

同时对照 `.soloent/rules/story-style.md` 的「人味」条款问一句：
**这一章有没有两处"没用"的东西？**（不推动情节、不交代信息，纯粹是人的毛边）

> 这条是**正向工艺规则**，不是禁令——它是"像人写的"最直接的抓手。

→ **留痕**：记下本步改了几处，写进第 5 步的 `[流程]` 行。

---

## 3. 技能三连（强制）

按顺序跑三个技能（SKILL.md 在 `assets/skills/<名字>/`）：

| 顺序 | 技能 | 管什么 |
|---|---|---|
| 1 | `chinese-punctuation` | 中文标点规范（含脚本 `scripts/fix_punctuation.py`） |
| 2 | `humanizer-webnovel-cn` | 真人味润色（网文男频版） |
| 3 | `pacing-control` | 节奏控制 |

**读每个技能的 SKILL.md 按说明执行**，不要凭名字猜它做什么。

→ **留痕**：记下三个技能各改了几处，合计写进第 5 步的 `[流程]` 行。

---

## 4. 连续性复查（强制）

对照 `world/`、`characters/`、`outline/伏笔回收总表.md`、记忆文件逐项核对。

**发现冲突先报告，不要自行改设定。**

→ **留痕**：记下发现并处理的冲突数（无冲突写 0），写进第 5 步的 `[流程]` 行。

> **2／3／4 三步为什么必须强制**：闸门验的是人名／刻度／字数／账本／黑名单词，
> **验不了 AI 句式结构、人味、钩子质量**。2026-09-18 的 ch-31、ch-32 两次漏跑，
> 作者当场反馈「AI 味重、不像人写的」。现在闸门会校验第 5 步的留痕行——**缺了就拦**。

---

## 5. 收尾回写（缺一步就过不了闸）

1. 更新 `.soloent/memory/now.md` **状态块**里的 `chapter`；
2. 把叙述性字段（`story_time`、`location`，以及你后来加的那些）补成该章结束时的状态；
3. 把 `narrative_verified` 也改成同一个章节号 ← **只许手改，`--fix` 不会碰它**；
4. **在 `.soloent/ledger.tsv` 追加一行**，列序见 `book.json` 的 `ledger.columns`：

   > ⚠️ **这一行是跨章对账的全部依据，写错一个字，后面几十章都在错的账上走。**

5. 同步 `now.md` 的叙述区（近期情节流、数值账目、人物快照、待处理线索）；
6. 每五章额外同步 `relations.md` / `world-rules.md` / `roadmap.md`；
7. **追加流程留痕行**（第 2／3／4／5 步的执行凭证，**闸门会校验并与之对撞**）：

   `[流程] ch-N 自查X 三连Y 复查Z 回写OK`

   X／Y／Z ＝ 该步**发现并修复**的处数。**干净章写 0 是正常的，但必须是真跑过的**。
   写在 `now.md` 的「流程留痕」小节。

   > ⚠️ **闸门不只看格式**：它会把该章的机检残留（黑名单词／句式禁项／同段连发／
   > 比喻堆砌／章末升华／面板条目）与「自查已完成」的声明对撞。**留有残留又没写明理由 = 拦截**。
   > 真跑过 B3 的章，机检看得见的那几类应当清零；`自查0 三连0 复查0` 只保证格式合法，
   > 不再等于通行证。确需保留的违规处写在行尾：`…回写OK；保留：<理由>`（降为警告，/review 复核）。

## 6. 出章闸门（强制）

```bash
python tools/preflight.py      # 退出码 0 才许写下一章
```

闸门同时校验**六件事**：

| 校验 | 谁在做 | 拦什么 |
|---|---|---|
| 单章正典一致性 | `consistency_check.py` | 人名写错、口径冲突、悬空设定、章末升华、句长节奏… |
| 状态是否已同步 | `state_sync.py` | 章写了但 `now.md` 没回写 |
| 账本是否平 | `ledger.py` | 跨章的数值/故事日/境界断裂（**单章检查看不见的那一层**） |
| 是否批量长跑 | 闸门自己 | 自上次过闸后一次新增 ≥N 章未逐章校验 |
| **第 2／3／4／5 步是否留痕** | 闸门自己（`flow_trace`） | `now.md` 缺本章的 `[流程]` 行；**或本章仍有 AI 味机检残留** |
| **上一章是否有评审记录** | 闸门自己（`review_blocker`） | 出第 N 章时 `notes/review-chapter-<N-1>-*.md` 不存在（`gate.review_required` 开启时） |

> 最后一项是 2026-09-19 加的。前四项都只能验「算得出来的东西」，
> 而**句法自查／技能三连／连续性复查天生算不出来**——只能验「有没有留痕」。
> 它拦不住"糊弄"，但拦得住"忘了跑"；而 9-18 的两次翻车恰恰都是忘了跑。

**不通过就停下修，禁止"先写着后面再改"。**

单项排查：

```bash
python tools/consistency_check.py --list-checks   # 打印机检项清单（唯一来源）
python tools/consistency_check.py ch-31           # 只查一章
python tools/state_sync.py --fix                  # 自动对齐可推导字段
python tools/ledger.py                            # 账本全量 + 破境投影
```

## 7. 质量审查（强制）

**闸门（第 6 步）只管算得出来的东西**——人名、年份、刻度、字数、23 个黑名单词。
**AI 句式结构、人味、钩子质量，机检天生看不见。** 这一层只能靠本步。

顺序不能反：**先过闸门清硬伤，再做质量评审。**

### ① 逐条扫 `ai-anti-patterns.md`

读 `assets/rules/ai-anti-patterns.md`，按 7 类句式 + 词级逐条对照本章：

| 类别 | 禁项 |
|---|---|
| 句式 | 否定排比（不是A不是B是C）／时间切片（一瞬间·刹那·这一刻）／「一股·一丝·某种」+抽象情绪／升级式升华／**「他知道」裁判腔**／排比三联／情绪定语化／推拉连词垫字（还没等他……） |
| 词级 | 忽然·突然·猛地（**一页 ≥2 即违规**）／柔化副词（缓缓·微微·轻轻·悄悄·默默）／生理模板（深吸一口气·心头一紧）／**比喻每章 ≤2**／眼睛文学（眸子·眼底划过）／空气时间拟态／复合修饰（A，却带着B） |

**判据：一页内同类句式出现 ≥2 次即判违规。**

### ② 走 `5-审查` 模块 3（正文质检）

读 `assets/skills/wuhang-long-all/5-审查/SKILL.md` 的**模块 3**，
以**毒舌读者／资深编辑**视角做段落级批注：沉浸感（Show Don't Tell、五感）、
情绪调动（爽／期待／憋屈，**憋屈不能过夜**）、文风红线，
重点标「出戏／啰嗦／逻辑不通」，**并给改写示范**。

### ③ 改完重跑闸门

改了正文就要重新过第 6 步——**过闸的正文才是定稿**。

> 对应**武行全流程第七步**（每章或每卷后跑 `5-审查`）。
> 跳过它，正文只过了一半的关：机检全绿，AI 句式整片漏过去。

---

## 8. 停下等确认

向作者汇报本章情况并**等待确认或修改意见**。

> **禁止连续生成多章。** 本库历史事故：19 章在 69 分钟内连发，
> 从第 15 章起人物名、性别、人设、年级全线漂移，错误无人核对，自我强化成"第二套设定"。

汇报时给这些信息：本章字数、闸门结果、有无警告、本章推进了什么、下一章计划。

## 可选：后台监视

```bash
powershell -ExecutionPolicy Bypass -File tools/start_watcher.ps1
```

启动后 `chapters/` 一有改动就自动跑对账＋过闸，结果写进 `notes/对账日志.md`。
**这一层与 agent 是否守流程无关**——它是前后台双层防线里的"后台"那层。

## 单章重设计（禁止整章重写）

如果某章要重新设计：

- **整章重写是禁止的。** 重设计 = 在旧稿上做外科手术（换触发、加因果、挪落位）。
- 动笔前先列**「保留 / 迁移 / 新增 / 删除」四列清单**呈作者确认。
- **已验证的文本资产（打磨过的台词、场景节奏、留白动作）只迁移不删除。**

> 这是第二次事故的教训：第一章重设计时整章重写，把四轮迭代过的文本资产整套丢弃了。
