## ★ 正典速查表（canon.md）怎么写

这是**整条链上最重要的一个文件**。它不是设定集，是**易错项速查**：
只放"最容易写错、且一旦写错就是硬伤"的值。

**该放的**：
- 人名、称谓、名讳的**唯一写法**（及常见错写）
- 数值与刻度（境界阶梯、每日收益、升级成本）
- 时间轴锚点（哪个事件距今几年、对应主角几岁）
- 锁定细节（某个地点/物件的唯一写法）
- 情报禁令（哪件事到第几章才能揭）
- 标点与格式约定

**不该放的**：完整人物小传、大段世界观设定——那些在 `world/` 与 `characters/`，
`canon.md` 只放指针与易错项。

## ★ 回头补 `book.json`（本阶段的核心动作）

数值体系定案后，把下面这些填进 `.soloent/book.json`。**不填的话工具就查不了这些**：

### 1. 评级刻度 / 境界阶梯

```json
"checks": {
  "scale": { "F⁻": [0, 19], "F": [20, 39], "F⁺": [40, 59] }
},
"ledger": {
  "rank_column": "rank",
  "rank_order": ["凡人", "练气", "筑基", "金丹"],
  "rank_max_jump": 1
}
```

- `checks.scale` → 正文里「评级词附近出现区间外数字」会被判可疑
- `ledger.rank_order` → 账本里境界倒退会被**拦截**
- `rank_max_jump` → 一次跨几档算跳级（有的体系允许大幅跳，填 `null` 关闭）

### 2. 账本列结构

初始只有 `ch / day / note`。定了数值体系后扩列：

```json
"ledger": {
  "columns": ["ch", "day", "nights", "rank", "pts_in", "pts_out", "pts_end", "note"],
  "int_columns": ["ch", "day", "nights", "pts_in", "pts_out", "pts_end"],
  "balance": { "in": "pts_in", "out": "pts_out", "end": "pts_end", "prev_end": "pts_end" },
  "income": {
    "cap_column": "pts_in",
    "rate_by_column": "rank",
    "rate_table": { "凡人": 1, "练气": 10, "筑基": 100 },
    "period_column": "nights",
    "exempt_note_words": ["灵果", "馈赠"]
  }
}
```

补上 `balance` 后就能查**平账**（上章余额 + 收 - 支 = 本章余额）；
补上 `income` 后能查**收入上限**（不能超过 期数 × 每日速率）。
⚠️ **列名改了，`.soloent/ledger.tsv` 的列序也要跟着改**，两处必须一致。

### 3. 升级成本与破境投影

```json
"ledger": {
  "rank_costs": [["练气入门", 10, "凡人"], ["筑基", 400000, "练气"]],
  "projection": { "goal_words": ["破境", "突破"], "day_regex": "第([一二三四五六七八九十百]+)天" }
}
```

补上后能从当前余额**投影出"哪天攒够"**，和细纲里写死的那天比对——
**能在写那一章之前好几章就发现排期对不上**。

### 4. 锁定细节与禁令

正文里第一次写死一个专有细节时，**当章登记**：

```json
"checks": {
  "locked_details": [
    ["地点·传功堂", ["传功"], ["传功(殿|阁|楼|院|房)"], "唯一写法＝「传功堂」（ch-02 立）"]
  ],
  "gated_keywords": [
    ["tian-sui", "天髓是天地自生", "天髓真相第 30 章前不得写死", [], 30]
  ]
}
```

- `locked_details`：行内出现语境词时，命中错误写法即判**严重**。
  **不登记 = 下一章很可能重造一个不一致的版本。**
- `gated_keywords` 第 5 个元素填解锁章号即自动放行（改一处即可）。

## 纪律

- **设定类拍板项一律先列建议与选项，agent 不得单方定案。**
- 骨架层（世界观/力量体系/人设/数值）的任何变动，先给选项等作者确认；
  确认后**当天在 `notes/` 留档**并一次性同步所有受影响档案，**未留档的变动视为未发生**。
- 每定一条正典，**同时**写进 `canon.md`（给人看）与 `book.json`（给工具看）。
